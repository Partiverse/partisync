# ADR-0003: 工具链 1.93.1 → 1.94.0（sqlx 0.9 前提）

状态: 已接受 · 日期: 2026-09-18 · 决策人: @lead（AI 代理起草，人工签核待补）
关联: ADR-0000（决策 2 的升级条款）、ADR-0002、SPEC M0-WP02

## 背景

sqlx 0.9.0（ADR-0002 既定选型）要求 rustc ≥1.94.0；仓库钉 1.93.1。
备选是降级 sqlx 0.8，但 0.9 是 2026 年主线（调研方案 §6），降级制造未来迁移债。

## 决策

rust-toolchain.toml 升级至 `1.94.0`。按 ADR-0000 升级条款执行全量回归：
fmt/clippy/test 全绿 + `scripts/bench.sh check m0` 基准对比（回退 >10% 需在此记录豁免理由）。

## 后果

- 全量构建缓存失效一次（可接受）；
- 基准结果需重新对照——回归证据记录于 M0 报告。

## 重新评估条件

- 1.94 出现安全通告 → 立即升级；
- sqlx 0.10 要求更新 rustc → 同本 ADR 流程。
