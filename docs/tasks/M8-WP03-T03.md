   registry 既有面）；一空间至多属一租户；换绑拒绝路径；
2. **RouteQuery 租户过滤**：联邦路由（M5-WP02 语义之上）增租户维度

   router）；
3. **隔离探针**：跨租户空间列举不可见；租户 A 的操作对租户 B 的
   audit/配额视图零泄漏（引空间级 KDF 密码学隔离判例，本任务只钉
   策略面）。
