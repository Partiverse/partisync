## 交付物

1. **epoch 主机制**：Engine 单例 `epoch_interruption(true)` + 100ms tick
   线程（daemon）+ 每调用 `set_epoch_deadline(预算 ticks)`；
2. **fuel 配额**：`consume_fuel(true)` + 固定常量 `FUEL_BUDGET`
   （1e9，10× 余量）——装载期预注入（Store 初始 fuel=0，canonical ABI
   起始 shim 计费）+ 调用期重置；
3. **错误语义**：trap 文案在 anyhow **根因层**（顶层只有 wasm
   backtrace）——root_cause 判别 `interrupt`/`fuel` →
   `CallError::Deadline`/`Fuel`；
4. **手工 Store helper**：`init_termination_budget`（deadline 大 delta
   防 `current+delta` 溢出；fuel 预注入）——测试/桌面壳直连调用方使用；
5. **探针**：spin_loop 死循环 fixture（手写 canonical ABI WAT）→
   Deadline/Fuel 真终止（实测 fuel 先到，~1s）+ 线程释放（后续正常
   调用成功）+ fuel 余量 + 回归；
6. **R8 核销报告**：`docs/reviews/M8-WP06-termination.md`。
