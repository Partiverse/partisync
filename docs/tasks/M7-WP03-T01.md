## 环境现实（R1 处置实录）

- 本机无 macFUSE/FUSE-T 且安装需 sudo 密码（headless 不可得）→ **降级
  路径②**：Docker Desktop Linux VM 向容器暴露 `/dev/fuse`（实测确认），
  真挂载在容器内执行（rust:1.94 pin 与仓 toolchain 一致）。
- macOS 本地路径：fuser 0.18 build.rs 实证——macOS 默认 probe macFUSE
  pkg-config，提供 `macos-no-mount` feature（编译验证用，本 spike 依赖
  已带；Linux 上 build.rs 先命中 pure-rust 分支不受影响）。真挂载若需
  macOS 本机（FUSE-T/NFS 桥兼容性）留复测触发条件。
