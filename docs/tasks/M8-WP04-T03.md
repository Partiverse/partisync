## 交付物

1. **业务 apply 接线**：m-entry/m-child 写路径改为 leader append →
   raft 日志 → apply → entry/tree 平面；raft_store 从通用存储面升级
   为业务 apply 载体；写确认 = 日志 quorum 提交；
2. **请求 id 幂等去重**：去重表随 apply 落盘，同 id 重放恰一次生效
   且返回首次结果；
3. **线性一致读**：leader 本地读 + follower ReadIndex（RFC F1 兑现）；
4. **P17 proptest**：并发写 + 交错读 ≥1000 例（注册行 P17 实现列
   回填探针路径）；
5. **崩溃矩阵接线**：RFC M3-WP02 M3-M6（分裂×复制相位）failpoint
   接线，重放后一致（P8 口径）；
6. **基准对照 + 核销表**：RouteQuery P99 / apply 吞吐对 M5-WP02/04
   口径无回归；RFC §8 五项逐项核销入 closure.md；
7. **顺带清偿**：F-2 endpoint_secret 合流（设备通道认证握手消费）；
   ADR-0015 三待确认项进场核实后回填（不可得则登记触发条件）。
