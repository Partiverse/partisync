## 交付物

1. **P18 转正实现**：链式哈希审计行（逐行 hash 含前行摘要）+ 篡改
   探针三类注入（改行/删行/交换序）必报；
2. **审计事件面**：HubCmd apply（Put/Remove/Rename）+ 管理面操作
   （registry/配额变更）→ `actor/action/object/ts/result` JSONL 行；
3. **异步 sink**：有界队列 + 独立写协程；**队满语义 = 阻塞写**
   （开放问题①裁定：合规立场，丢审计不可接受），背压指标可观测；
4. **导出**：`audit export --from --to` → JSONL 文件 + 链头链尾
   digest（可独立复算）。
