## 交付物

1. **计量面**：per-space 逻辑字节累计（CAS 逻辑内容字节口径，非
   EC/pack 物理放大——文档明示口径）；计量随 apply 更新（复用
   EntryRow.size 聚合，增量维护不重扫）；
2. **硬限**：超限 → `QuotaExceeded` 结构化错误（映射表含 FUSE 侧
   ENOSPC 路径注记，挂载接线归 M8-WP07）；错误先于 apply 提交
   （拒绝先于破坏性效果）；
3. **软告警**：默认 80% 阈值触发一次事件（沿 UploadAck 事件面通知
   形态）；阈值可配置；
4. **计量准确性探针**：写入/删除/改名后计量值与逐行 sum 对照
   ≤ 容差。
