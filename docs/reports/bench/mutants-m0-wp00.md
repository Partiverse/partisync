**缺口→补强对照**：

- `stats` 的 saved `-`→`+` 存活 → **现有测试只断言差值**（`st2 == st1 + len` 在变异下恒真）
  ——「断言弱于规格」的又一实例，补绝对值断言（0 与 len）。

**流程事故与整改（本次实际踩坑）**：`--in-place` 模式变异会临时改写工作区源码，
与并行 git 操作存在冲突窗口（本次 `git add -A` 恰逢活跃变异，事后核查 HEAD 无污染，
working tree 由 mutants 自动还原）。整改：`scripts/mutants.sh` 禁用 `--in-place`，
固定使用默认临时副本模式；运行时产物（partisync.db*/cas/mutants.out*）入 .gitignore。
