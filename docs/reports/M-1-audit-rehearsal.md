## 3. 体系有效性结论（演练要回答的问题）

1. **追溯链可重建**：`cargo xtask trace M-1-WP07-T01` 输出提交 → SPEC → AI 披露 → 触及文件完整链，
   未参与开发者可据此重建「为什么做（SPEC 动机）→ 要求什么（契约）→ 做了什么（diff）→ 如何证明（测试）→ 谁做的（trailer）」。✅
2. **测试先行可执行**：桩合入时套件可编译、红的证据明确；实现后同套件转绿，无测试改动（S5 期间仅按审查发现**新增**回归测试，未修改既有断言）。✅
3. **对抗审查有效**：审查发现 F1（溢出判断误判非首字符）为**既有测试集无法捕获的真缺陷**
   ——属性测试全走合法编码路径，恰好绕开该边角。这验证了「变异测试 + 对抗审查」双保险的必要性
   （变异基建为 M-1 债务，见里程碑报告 §5）。✅
4. **自动化统计可用**：`cargo xtask report M-1` 自动产出 AI 使用披露（7/7 AI 辅助、0/7 人工终审——真实反映演练性质）。✅
