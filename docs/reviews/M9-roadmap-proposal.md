## 1. 动机

M8 G3 三签落档（`2a3ebb5`，2026-10-03），八 WP 全关账：v0.1.0-alpha
签名版已 publish（2026-10-02）、FUSE 写回二期 + `/by-hash` 收官、治理
一期（审计/配额/多租户）落地、Hub-raft 最老地基债清偿、epoch/fuel
终止保障实装。M8-WP00 §2 留下两项 M9 开局复核义务（移动端时点、资金
回笼窗口），§6 非目标把五个方向显式挂到 M9。此时制定 M9 计划的必要性：

1. **产品闭环缺口已变成最大空白**：挂载写与桌面写已可产 EventRecord，
   但 sync session 装配缺失——**本地写不向其他端同步**，单机孤岛面是
   同步产品的定位级缺口（M8-report §8-2 实测登记）；
2. **两个外部窗口有时钟**：可验证本地记忆层（CAS+Merkle+MCP 组合）
   外部零竞品（演进调研 §2.2/§4，中高可行性）；MCP 2.0（2026-07-28
   spec）与 WASI 0.3 双定稿窗口 6–12 个月（演进调研 §3-4）；
3. **资金节奏反证**（Spacedrive 重写致死 / Immich 靠资助）→ 发布实跑
   与收入叙事优先于新功能加深（演进调研 §3-5），v0.1.0-beta 是现成
   下一个发布节点（签名管线 M8-WP02 已备）。

## 3. 赛道趋势输入（引 2026-10-01 演进调研，本提案不重跑）

1. **格局**：Spacedrive V2 资金断档停更、出局；「跨设备文件域 + E2EE +
   企业可审计 + 收入可持续」交叉点无人占据。照片域心智被 Ente/Immich
   占据，不进入。
2. **企业化路径** = Proton 顺序（SOC 2 证据 → 审计/配额 → SSO → CLI/SDK
   → 套件）；PartiSync 已走到第三格前（审计+配额 ✅，SSO 未动）。单人
   带宽下企业线止于审计+配额+CLI（演进调研 §4 对冲行）。
3. **AI 检索**：on-device 小模型是 E2EE 约束下唯一路径（Ente 实证）；
   文件域本地语义检索是确认空位 → 桌面旗舰功能候选。
4. **扩展信任**：WASM 签名分发收敛 cosign/OCI（不自建 registry）；
   MCP 官方 registry 仍不验 artifact 签名——空位仍在。
5. **最大风险 = 资金节奏** → 发布优先于新功能；「先重写后收入 = 死局」
   教训直接映射为「先 beta 后深耕」。

## 4. 战略方向评估（M9 四条候选路线；推荐为纸面推断，待拍板）

| 方向 | 内容 | 支撑 | 风险/代价 | 排序建议 |
|---|---|---|---|---|
| **α 记忆层一期**（Verifiable Local Memory） | N2 空位：记忆资产 schema + MCP 工具面（写/检索/证明）+ Merkle inclusion proof 对外 API；本地 stdio 先行，Hub 远程化随 WP 分期 | 零竞品窗口；CAS+Merkle 是别人没有的地基；学术 spec（Portable Agent Memory）可引用 | 新资产类型入 graph schema（演进债）；「记忆」范围须收窄防面广 | **主线推荐** |
| **β 写路径闭环**（N1） | 挂载写/桌面写 → sync session 装配端到端；watermark F1 清偿点 | 定位级缺口；M8-report §8-2 点名；F1 债同源清偿 | 触碰 sync 核心装配面（R1 全审）；冲突语义须走 SEMANTICS 修订 | **主线推荐**（与 α 并行序靠前） |
| **γ 产品化发布** | v0.1.0-beta 实跑 + UI 硬化 + 本地语义检索旗舰 + drop-caches 复测窗口 | 资金节奏第一判据；签名管线已备 | beta 口径需拍板（是否含 FUSE 写回） | **主线推荐**（压轴节点） |
| **δ 信任面小步** | 扩展签名分发对齐 cosign/OCI（不自建 registry）+ MCP 2.0 远程 server 评估 | G6 空位；窗口敏感（6–12 月） | 远程 MCP 涉 OAuth 2.1 PRM 新安全面，一期可只做评估+骨架 | 穿插小步（WP 级拆小） |

**推荐组合逻辑**（待拍板）：M9 走 **α+β+γ 三主线、δ 小步穿插**——
β 写路径闭环是 α 记忆层的前置（记忆写入走同一条 sync 装配），γ beta
是两者的对外交付节点；δ 拆成不阻塞主线的签名小步 + 远程 MCP 评估 WP。
SSO/治理二期不进 M9 主线（企业需求未验证真实 + Proton 顺序未到格），
外部审计维持资金回笼条件触发。

## 8. 结论

M8 把「可分发、可治理、可信任的地基」补齐后，M9 的价值台阶有三层：
**本地写真正同步**（β，定位级缺口清偿）、**把引擎的 CAS+Merkle 地基
变成对外可验证的记忆层**（α，零竞品窗口）、**beta 发布守住资金节奏**
（γ，Spacedrive 反证）。三者构成一条交付链：WP01 写装配 → WP02 记忆
层 → WP03 桌面承接 → WP06 beta 压轴；信任面（δ）拆小步穿插不阻塞。
本提案若获批，M9-WP00 沿 M8-WP00 判例正式化 WP 图并逐 WP 走 SPEC 批准。
