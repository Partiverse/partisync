## 2. 排序推荐案（待用户修订权）

**GA 先行，CLI 强化 GA 后实施**：WP02（纯 docs，随时可做）→ WP01
T01（可先行件）→ WP03 → WP01 T02–T04（等 J1 计满）→ WP05（评估随
窗口穿插）→ **WP04 作为 GA 后主线**（SPEC 细化与提案可并行先行，
实施合入落在 v0.2.0 tag 之后，走 v0.3.0 线）。

推荐理由：cadence J4 = 「GA tag 前 B1–B8 复跑全绿」语义是对 **rc.1
已验证面**的复核；若 CLI 强化抢在 tag 前合入，GA 面扩大、复跑拉长、
GA 时点顺延，且窗口期 rc.2 删 tag 重打规则（cadence §2）会被新功能
开发误触发。WP04 的 SPEC 起草不产代码，可全程并行不阻塞 GA。
