## 1. 动机

M9 关账件（里程碑报告 PR #151，2026-10-05）落档：35/35 PR CI 全绿、
追溯链抽查 5/5 PASS、AI 披露 100%。四个 WP 收官（WP01 写路径闭环 /
WP02 记忆层一期 / WP03 桌面深耕实施面 / WP04 扩展强制验签），两个 WP
半程（WP05 骨架交付收尾待做 / WP06 准备件就绪发布待执行）。此时制定
M10 计划的必要性：

1. **M9 两笔半程债有时钟**：v0.1.0-beta 准备件就绪但发布动作待用户
   确认口径（M9-report §1-WP06）——资金节奏第一判据（演进调研 §3-5
   「先重写后收入 = 死局」反证）仍未兑现；WP05-T02 收尾回填是半天级
   开局件；
2. **M9 主线交付制造了新的下一层空白**：记忆层一期只交付「写入—检索
   —证明」单向面，无 update/delete/GC 生命周期、无向量检索（M9-report
   §8-5 登记）；MCP 远程停在 mock 骨架（G8 半清偿，真实 OAuth 2.1 /
   TLS / 工具透传的必答题 O2/O3 已列）；CAS 大文件不可重组（WP03-T06
   新债）；
3. **两个条件触发项的触发条件在 M9 期间已满足**：AI workflow 编排
   （G10）前置 =「记忆层一期验证后」——M9-WP02 已收官；移动端 M10+
   时点义务按 M8-WP00 §2 判例须在 M10 开局再复核。条件行不自动入
   主线，但必须在提案里逐项显式裁决（入线 / 维持挂起 / 评估件），
   否则候选池悬空。

## 3. 赛道趋势输入（引 2026-10-01 演进调研，本提案不重跑）

1. **资金节奏第一判据维持**：Spacedrive 重写致死反证 → beta 发布
   优先于一切新面加深（NB1 是 M10 开局最高优先事项而非可选件）；
2. **MCP 2.0 窗口（6–12 个月，自 2026-07 定稿起算）仍在**：远程
   server + OAuth 2.1 PRM 的对齐评估已完成（M9-WP05），正式化的
   成本从「评估」降到「接线 ADR + 实施」——窗口后半段优先级上升；
3. **可验证本地记忆零竞品空位仍在**（演进调研 §2.2/§4）：M9 一期
   已占位但只覆盖单向写入面；生命周期管理（update/delete/GC）与
   检索深化（向量）是空位从「占位」变「守住」的二期动作；
4. **企业化路径 Proton 顺序未到格**：SSO 前置（企业需求真实验证）
   未发生，治理二期维持条件触发不变；
5. **AI 编排**：演进调研将「声明式规则管线 + 可视化编排」列为 G10
   锚点项，且与记忆层强耦合（事件 → 记忆读写 → 动作）——记忆层
   一期落地后编排的输入输出面首次齐备，具备出评估件的条件。
