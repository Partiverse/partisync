# RFP: partisync 外部渗透测试与安全复核（D2 清偿）

## 1. 项目背景与目标
partisync 是一套跨端本地优先的资产图谱与数据同步基础设施，近期完成了 M4 里程碑交付，包含 MCP（Model Context Protocol）网关、Sidecar 推理管线以及 iroh QUIC 传输层通道。

为完成 M4-G3 里程碑正式安全审计闭合（D2 清偿），项目已执行内部 5-大模型（GLM-4.7-flash, ERNIE-4.5-turbo, Spark-4.0Ultra, Qwen3-8B, GLM-4-9B）自动化对抗性黑盒红队测试，覆盖 STRIDE 32 项威胁，并完成了针对高危项（如 `dataset_export` 向量泄漏、`asset_organize` 批量 DoS、未授权批量操作认证绕过等）的代码加固。

现诚邀具备合格资质的专业安全顾问或安全团队对加固成果进行独立复核与黑盒渗透测试。

## 2. 参选资质要求（Mandatory Criteria）
1. **资质证明**：主评测人员须持有有效 **OSCP**（Offensive Security Certified Professional）或同等行业公认实战认证（需提供证书编号以便官网验证）。
2. **专业背景**：具备至少 3 年以上 Rust 代码审计或基于 Rust 编写的网络协议/系统安全测试经验。
3. **技术栈熟悉度**：熟悉 LLM/AI Agent 交互协议（如 MCP 协议）、QUIC/TLS 网络通信协议及常见系统级逻辑安全漏洞。
4. **沟通能力**：支持中文或英文书面沟通，具备良好的安全缺陷归档与复现用例编写习惯。

## 3. 工作范围与测试模式（Scope of Work）
- **预估工作量**：4 小时（0.5 个工作日）专项高密度测试 + 30 天漏洞修复复测窗口。
- **阶段一：输入材料评审（2 小时）**
  - 审阅自动化红队评估报告 `docs/reviews/SEC-AI-PENTEST-M4-WP06-001.md` 及 STRIDE 威胁矩阵。
  - 审阅 M4-WP99 加固提交（涉及 `partisync-gateway/src/mcp.rs` 中的输入检验、权限校验、批量操作约束）。
- **阶段二：黑盒实战渗透与验证（2 小时）**
  - 目标对象：本地启动的 `partisync-gateway` MCP 工具服务（基于隔离沙箱目录运行）。
  - 测试重点：
    1. MCP JSON-RPC 输入边界绕过、未过滤参数注入。
    2. `asset_organize` / `dataset_export` 等批量接口的越权访问或资源消耗型 DoS。
    3. 协议逻辑缺陷：鉴权绕过、侧信道信息泄露。
- **阶段三：交付与复核**
  - 提供单页签名版渗透测试报告（包括执行摘要、复现 POC 步骤、风险评级 CVSS）。
  - 针对修复方案进行一次闭环复验确认。
