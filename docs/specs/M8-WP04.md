版本: 0.1 · 状态: **草稿**（2026-10-01 起草，随 PR 入仓待批准；批准状态

## 1. 动机

RFC M3-WP02（2026-09-21 人工终审通过）把 raft 分片元数据的线性一致
语义设计定稿，但 §8 如实移交：业务平面从未接线。现状是「承诺与实现
脱节」——`Hub::open(root: &Path)`（`crates/partisync-hub/src/lib.rs:75`）
无节点身份/组拓扑概念，`raft_store` 是通用存储面（apply 只落通用数据
节），m-entry/m-child 业务写不经 raft 日志，请求幂等去重缺失，follower
线性一致读未提供。这是全仓**最老未结移交债**（M3 起），随 Hub 治理
平面（M8-WP03）与企业叙事逼近，越晚接线改面越大。

不接线则 M8-WP03 的审计日志/配额建立在一个可分叉、可重放的存储层上
——治理面的 audit trail 无「线性一致」背书，企业语义站不住。

## 2. 契约（草稿级，批准即冻结；精确签名在任务卡定稿）

### 2.1 节点身份与组拓扑

- Hub 构造路径增节点身份参数：`NodeConfig { node_id, group_id, peers }`
  （命名实施期定）；现有 `Hub::open(root)` 保留为**单节点降级路径**
  并作为回归基线（行为契约不变：put_entry/get_entry/list_children +
  读时修复）；
- 组注册表持久化（m-meta keyspace）：重启后拓扑恢复，节点身份持久
  不漂移。

### 2.2 业务平面经 raft apply（本 WP 最大改面）

- m-entry/m-child 业务写路径改为：leader append → raft 日志 → apply
  → entry/tree 平面；`raft_store` 从通用存储面升级为业务 apply 载体；
- apply 幂等：同一 raft 日志条目重放（崩溃恢复）结果一致（沿 P8 语义）；
- 写确认语义：客户端确认 = 日志已提交（quorum），非仅 leader 内存。

### 2.3 线性一致读

- leader 本地读 + follower ReadIndex（RFC 裁定 F1 兑现）：follower
  读经 leader 确认当前 commit index 后返回，保证读单调；
- **新不变量候选 P17**（并发写单调性：已观察到的写结果不被后续读
  回退）——实施**前**走 partisync-property-registry 转正（P16 已被
  M8-WP07 预订）。

### 2.4 请求 id 幂等去重（RFC §3.1）

- 写请求携带请求 id；去重表持久化（随 apply 落盘），同 id 重放不产生
  双应用且返回首次结果。

### 2.5 顺带清偿（不扩范围，随接线自然消费）

| 债 | 处置 |
|---|---|
| F-2 endpoint_secret 与 iroh 传输未合流（SEC-AI-AUDIT-M7-WP02 §6） | 设备通道认证握手消费 endpoint_secret，合流后 P3 债销账 |
| ADR-0015 三条待确认项（relay 定价 / ALPN 互操作 / 上传窗口） | 进场核实/实测后回填 ADR-0015 待确认表；不可得时登记触发条件 |

## 3. 验收标准（可执行）

- [ ] **RFC §8 移交项逐项核销表**：五项（节点身份/组拓扑、follower
      线性一致读、分裂×复制 M3-M6 + m-meta、请求 id 幂等、业务平面
      apply 接线）逐项对照证据入 `docs/reviews/M8-WP04-closure.md`；
- [ ] **单节点回归基线**：现有 `Hub` API 全部行为测试/proptest 不改
      断言全绿（铁律：不放宽既有断言）；
- [ ] **读单调 proptest**（P17）：并发写 + 交错读 ≥1000 例，已观察
      值不回退；
- [ ] **幂等探针**：同请求 id 重放 N 次 → apply 恰一次（计数断言），
      返回值与首次一致；
- [ ] **崩溃矩阵**：RFC M3-WP02 崩溃矩阵 M3-M6（分裂×复制相位）
      failpoint 接线，重放后一致（P8 口径）；
- [ ] **基准对照**：RouteQuery P99（M5-WP02 口径 298µs 基线）与 apply
      吞吐（M5-WP04 口径 508k evt/s 基线）无回归（阈值任务卡定，劣化
      须 ADR-0026 式修订留痕）；
- [ ] 三件套零新增豁免 + CI 全绿；覆盖率只升不降（铁律 5）。
