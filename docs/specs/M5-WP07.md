# SPEC: M5-WP07 —— usearch 写吞吐阻塞项清偿（10⁵+ 向量口径补测）

版本: 0.1 · **状态: 批准（依用户「继续」指令，按 M5 先例视同批准）** ·
关联: M5-WP05 报告 §4（向量写入 10⁹ 外推 = 阻塞项）、§7 后续卡 1 ·
上游: `index::search::vector`、usearch 2.26
负责人: @lead · 起草日期: 2026-09-25

## 动机与目标

M5-WP05 基准实测 `VectorStore::add`（含已修复的 `add_new` 快路径）在本环境
~4–16ms/条（release + 预 reserve，768d Cos）——HNSW add 理论应为 µs 级，
偏差 1000×，10⁵ 构建不可运营。本卡定位根因并修复（或如实登记为上游
缺陷 + 绕行方案），补测 10⁵ 向量口径。

## 裁定

1. **根因定位先行**：纯 usearch rust API 隔离探针（绕开 wrapper）区分
   「库慢」vs「wrapper 慢」；再区分 debug/release、reserve 前后、
   IndexOptions 参数（connectivity/expansion/quantization）。
2. **修复路径（按嫌疑序）**：① IndexOptions 调参（connectivity 默认
   值过大、quantization F32→F16/I8）；② 批量 add API；③ 上游缺陷则
   绕行（换 batch 重建 / 换库需 ADR）。
3. **零新增依赖**；换库 = ADR 另立。
4. **验收**：10⁵ 向量构建 ≤ 5min（≥330 条/s 等效 ≥100× 现状或如实
   登记）；vector top-10 @10⁵ P99 < 100ms 补测进 M5-WP05 报告（修订
   记录追加）。
