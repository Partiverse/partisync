## 1. 动机

M6 §6.7 滚动产品化的最高可见度交付是「Tauri 2 桌面壳」。 当前
M6-WP01 已落地 CLI + 浏览器单页演示面（`partisync ui` 命令启 axum
于 `127.0.0.1:RANDOM`， 见 SPEC M6-WP01），但浏览器 tab 形态缺失
**原生窗口体验**： 系统托盘、 Dock 图标、 启动闪屏、 菜单栏、
全局快捷键、 窗口位置/尺寸记忆、 键盘焦点切换。 这些是
投资演示/招聘 demo/用户上手场景的硬需求。

不解决的代价：

1. 投资演示只能 demo CLI 与 axum HTTP， **GUI 演示缺位**；
2. WASM 扩展系统（M6 §6.7 第二项， M7+ 评估）天然依赖
   Tauri-like 沙箱边界， 桌面壳即其脚手架；
3. 招聘场景候选人无法「一键启动看产品」， 需 docker-compose 跑
   demo 服务——摩擦成本高。

本期范围明确「**macOS + Linux 桌面优先**」， iOS/Android 留 M7+
单独决策（webkit-mobile 路径与 wry 桌面路径构建差异显著， 涉及
Xcode/Gradle 工具链与移动安全模型， 超出本 WP）。

## 2. 契约

### 2.1 二进制入口

```
partisd-desktop [--dev] [--port <tcp_port>] [--data-dir <path>]
```

- 默认 `127.0.0.1` 绑定的 axum 子服务（侧车 `partisync-cli ui` 行为
  兼容）； `--dev` 启 devtools（仅 `cfg(debug_assertions)`）
- `--port` 透传给侧车 `partisync-cli ui`， 默认 8080
- `--data-dir` 覆盖默认 `~/.local/share/partisync-desktop/`
  （Linux）/`~/Library/Application Support/PartiSync/`
  （macOS， dirs crate 与既有 `partisync-cli` 一致）

### 2.2 窗口契约

- **macOS**： WKWebView， 1200×800 默认尺寸， 位置/尺寸记忆于
  `<data-dir>/window-state.json`， 关闭时持久化
- **Linux**： webkit2gtk-4.1 WebView， 同尺寸与位置记忆； 需运行时
  `libwebkit2gtk-4.1.so.6` 探测， 缺失时给出可读错误（不 panic）
- 标题栏： 「PartiSync · 资产图谱」； macOS 标准交通灯，
  Linux GTK 装饰
- 启动闪屏： 200ms 黑屏 → 主窗口（无第三方 splash 图， 仅背景色
  过渡； splash 图片设计属企业特性议题， 本期不引入）

### 2.3 IPC 契约（Tauri commands）

所有命令注册在 `crates/partisync-desktop/src/ipc.rs`， 由前端
`window.__TAURI__.invoke(cmd, args)` 调用：

| 命令 | 入参 | 出参 | 实现路径 |
|------|------|------|---------|
| `get_stats` | — | `{files, dirs, total_bytes, unique_contents, unique_bytes, duplicate_groups, saved_bytes}` | 直链 `partisync-graph::store::Stats` |
| `list` | `{prefix: string}` | `Vec<EntryRow>` | 同上 |
| `search` | `{q: string, limit?: u32}` | `Vec<{content_id, score, highlight}>` | 直链 `partisync-index::IndexEngine::bm25_only`（与 `partisync search` CLI 对齐， M4-WP02） |
| `cas_stats` | — | `CasStats` | 直链 `partisync-cas::ChunkStore` |
| `duplicates` | `{top: u32}` | `Vec<DupGroup>` | 同 get_stats 路径 |
| `jobs` | — | `Vec<JobRow>` | 直链 `partisync-graph::jobs` |
| `mcp_call` | `{tool: string, args: json}` | `json` | spawn 侧车 `partisync-mcp` stdio 进程 |

> **T03 / T05 边界**： 上表 7 命令中 **T03 实施 6 个** （`get_stats` /
> `list` / `search` / `cas_stats` / `duplicates` / `jobs`）， 第 7 个
> `mcp_call` 侧车连通属 **T05 范畴** （§3 T05 验收 + §6 R5 处置）。
> `crates/partisync-desktop/src/ipc.rs` T03 期仅注册 6 个 command
> 处理器； T05 再扩 `mcp_call`。

### 2.4 跨平台行为

| 平台 | webview 后端 | 状态 |
|------|--------------|------|
| macOS 11+ (Big Sur) | WKWebView（系统） | ✅ 一类支持 |
| Linux x86_64/aarch64 + webkit2gtk-4.1 | webkit2gtk | ✅ 一类支持 |
| Linux + 仅 webkit2gtk-4.0（旧版） | — | ❌ 启动时报错退出 |
| Windows | WebView2（Edge） | 🟡 二类支持（README 标注， CI 不强测） |
| iOS / iPadOS | — | ❌ 本 WP 范围外 |
| Android | — | ❌ 本 WP 范围外 |

### 2.5 性能承诺

| 指标 | 目标 | 实测要求 |
|------|------|---------|
| 冷启动 → 主窗口可交互 | < 1.5 s（macOS M1） / < 2 s（Linux x86_64） | `cargo xtask bench desktop-cold-start` |
| 内存占用（空索引库） | < 200 MB RSS | 同上 |
| `search` IPC RTT | < 30 ms（10k doc 索引） | Tauri 自带 command 时延日志 |
| 二进制增量（vs `partisync-cli`） | < 5 MB（无 Chromium） | `ls -lh` 对比 |

### 2.6 错误语义

| 错误码 | 触发条件 | 前端处理建议 |
|--------|---------|-------------|
| `WebviewMissing` | Linux 缺 webkit2gtk-4.1 | 启动时 toast：「请安装 `webkit2gtk-4.1`」+ 文档链接 |
| `DataDirUnwritable` | `--data-dir` 路径无写权限 | 启动时对话框（GTK/Qt 原生） |
| `SidecarSpawnFailed` | `partisync-mcp` 启动失败 | IPC 错误返回 `{kind: Sidecar, msg}` |
| `IndexUnavailable` | 首次 `search` IPC 时 `IndexEngine::open_or_create` 失败（无 tantivy / 向量索引目录不可写 / 索引损坏） | IPC 错误返回 `{kind: Index, msg}`， 前端降级提示「BM25 索引未就绪」 |
| `TauriCommandPanicked` | command 内 panic | IPC 错误返回 `{kind: Internal, msg}`， 前端 console.error |

## 4. 非目标

| 项 | 推迟至 | 理由 |
|----|--------|------|
| iOS / iPadOS 移动壳 | M7+ | wry 移动路径构建差异显著（Xcode 项目）； 涉及移动安全模型 |
| Android 移动壳 | M7+ | 同上（Gradle 集成） |
| WASM 扩展系统接入 | M7+ | §6.7 第二主题； 本 WP 仅留 Tauri IPC 边界脚手架 |
| 自定义协议 URI（`partisync://`） | M7+ | OS 注册流程与本期 MVP 解耦 |
| 代码签名 + 公证（macOS notarization） | M7+ / 企业特性议题 | 涉及 Apple Developer ID 凭证 |
| Linux 发行版打包（.deb / .rpm / AUR） | M7+ | 涉及多发行版维护矩阵 |
| Windows 一类支持 | M7+ | WebView2 路径需独立验收； 本期 CI 不强测 |
| 自定义 splash 图 + 公司品牌 | 企业特性议题 | 设计资产未到位 |
| 内置 `partisync index` 触发（GUI 一键索引） | M7+ | 本期只读浏览， 写索引走 CLI |
