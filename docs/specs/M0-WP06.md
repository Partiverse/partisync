# SPEC: M0-WP06 —— CLI 检索矩阵（ls / find / dedupe）

版本: 1.0 · 状态: 批准 · 关联: 执行方案 §6.1-WP06 · 上游: SPEC M0-WP02
负责人: @lead · 批准日期: 2026-09-18

## 动机
M0 收口：检索能力不依赖网页（脚本/管道场景），CLI 对齐 rclone 的日常操作面。

## 契约（薄封装，底层 API 已测）
- `partisync ls [--db] <path>`：列目录（目录在前、名称序），文件显示大小与内容前 8 位
- `partisync find [--db] <q>`：名称子串检索，上限 200 条
- `partisync dedupe [--db] [--top N]`：重复组清单 + 汇总（组数/浪费字节）

## 验收标准
- [ ] 三命令对真实库（partisync-big.db）输出正确（与 /api 端点交叉核对）
- [ ] fmt/clippy/test 全绿

## 非目标
JSON 输出模式（--json 归 M1，供脚本消费）；分页（LIMIT 200 固定）。
