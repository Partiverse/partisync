## 1. 动机

执行方案 §6.7 四主题中「SMB 桥接评估」「企业特性」在 M6 滚动拍板下未
立项、顺延 M7（M6-report §1 明确记录为顺延非裁剪）；2026-09-29 用户
拍板正式立项为 M7-WP03（M7-WP00 §2）。企业侧真实需求是：局域网内
Windows/macOS 客户端以 SMB 访问 PartiSync 资产图谱——但调研方案 §3.4
已定路线：**Rust 原生 SMB 服务端栈不成熟，v1 不实现线协议**；正解是
FUSE（fuser）前置本地 POSIX 语义挂载，SMB 需求经 Samba 桥接该挂载点。

本 WP 是**评估 WP**（沿 M6-WP04 WASM 评估判例）：不动产品依赖图，
用 spike 实测 FUSE 路线的技术边界（mountpoint-s3 式「诚实非 POSIX」
语义在本仓库数据面上的适配度），纸面评估 Samba 桥接约束，登记企业
特性议题（含 WP01 遗留的扩展分发/签名/registry 供应链面），产出是否
立项实施 WP 的决策建议。不解决的后果：SMB 需求无落地路径，企业特性
（扩展分发信任链等）持续悬置且 WP01 扩展生态在无签名/registry 下野蛮
生长。

## 2. 契约（评估 WP：产出为评估结论，非代码行为契约）

- **产品依赖图零改动**：根 `Cargo.toml` workspace members 不变；fuser
  只允许进独立 spike workspace（`crates/partisync-fuse-spike/` 自带
  `Cargo.lock` + `deny.toml`，不入根——M6-WP04 `partisync-wasm-spike`
  判例）。
- **语义诚实**（调研方案 §9.3）：FUSE 挂载面必须发布 SEMANTICS.md 式
  语义声明——随机读 + 新文件顺序写支持，覆盖/改名/删除等未声明操作
  **显式拒绝**，不做含糊「全 POSIX」承诺。候选不变量 P15 随 spike
  登记（实施 WP 时转正）。
- **API 零凭记忆**：fuser 线位与 API 形态以 spike 实测为准（红线：
  禁止凭记忆编写第三方 crate API）；线位结论入 ADR-0026 草案。
- **结论分级**：评估报告结论须区分「实测证据」与「纸面推断」，禁止
  纸面推断伪装成实测（沿 M6-WP04 六项基准全部可测量的口径纪律）。

## 4. 非目标

| 项 | 推迟至 | 理由 |
|----|--------|------|
| SMB/NFS 线协议实现（Rust 原生） | 无限期（路线否决） | 调研方案 §3.4 现实决策；桥接 Samba 替代 |
| FUSE 实施 WP（产品依赖图内 fuser） | 评估结论 + 用户拍板后（M8 候选） | 本 WP 为评估；依赖须 ADR-0026 批准 |
| 写回日志 + overlay 实现（覆盖/改名/删除） | 实施 WP 二期 | 调研方案 §3.3 差异化项；一期只读语义先立 |
| 企业特性实施（签名/registry/配额等） | 议题登记 → 用户拍板 → 独立 WP | 供应链面需独立威胁模型（WP01 §4 继承） |
| macOS FUSE 打包分发（bundle 内嵌 FUSE-T） | 实施 WP 后期 | 先验证技术边界再谈分发 |

## 6. 风险与开放问题

| # | 风险 | 概率 | 影响 | 处置方向 |
|---|------|------|------|----------|
| R1 | 本机无 FUSE 环境（2026-09-30 实测：无 macFUSE/FUSE-T）→ spike 实测不可行 | 高 | 高 | 三级降级：①用户安装 FUSE-T（一条 brew 命令，登记为环境前置）；②Linux 实测环境（用户机/容器）；③纸面评估 + 显式标注（验收允许但须留复测触发条件） |
| R2 | GitHub runner 无 `/dev/fuse`，CI 无法真实挂载 | 高 | 低 | CI 仅编译 spike + 单测语义层（探针的拒绝路径可纯单测）；真实挂载实测全部本机执行（沿 T04 冷启动 bench 自主跑通判例） |
| R3 | fuser × FUSE-T/macFUSE 兼容差异（FUSE-T 走 NFS 桥，语义边界与 macFUSE 不同） | 中 | 中 | spike 探针显式记录运行环境（哪层 FUSE）；语义结论按环境分栏 |
| R4 | Samba 桥接纸面评估置信度不足 | 中 | 中 | 报告强制区分实测/纸面（§2 契约）；纸面结论附复测触发条件 |
| R5 | 企业特性议题范围蔓延（配额/多租户等无限展开） | 中 | 低 | T03 只登记不设计——威胁模型草案限扩展分发/签名/registry 三项，其余进候选清单表 |
| R6 | fuser 线位与 1.94 toolchain 不兼容（沿 wasmtime 48/49 判例） | 低 | 中 | spike 实测定线位；不兼容则在 ADR 草案登记版本矩阵（升级 toolchain 前不可采纳） |
