## D6 三推理栈真模型冒烟

**已就绪面**： `partisync-ai` 已有 OCR/embed/transcribe 三 stage（WP01 收官），
feature 门控（`ai-ocr/ai-embed/ai-transcribe`），fastembed TextInitOptions
接 BGE。

**冒烟口径**：
- embed：BGE-small-zh-v1.5 在 200 doc LCSTS 子集上端到端： build
  索引 → 跨 query 检索 → 首次 P50/P99 + 召回率
- OCR（可选，模型大跳过）： 仅记录 feature 路径实装存在， 不冒烟
- transcribe： 同 OCR 跳过（需音频语料）

**报告**：`docs/reports/bench/M5-D06-inference-smoke.md`（占位，
D6 实质冒烟即 + commit）。
