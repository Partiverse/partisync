## 0. 动机

M8 G3 关账（`2a3ebb5`）后八 WP 全闭合：v0.1.0-alpha 已 publish、FUSE
写回二期 + `/by-hash` 收官、治理一期落地、Hub-raft 地基债清偿、
epoch/fuel 终止保障实装。M9 的三个价值台阶（提案 §1 实测登记）：

1. **N1 本地写不同步**——挂载写已产 WAL，但无进程折叠为事件、无进程
   驱动 push/bisync，单机孤岛面是同步产品的定位级缺口；
2. **N2 记忆层空位**——CAS+Merkle+MCP 组合外部零竞品（演进调研
   §2.2/§4），窗口 6–12 个月（MCP 2.0 / WASI 0.3 双定稿）；
3. **N3 beta 节点**——资金节奏反证（Spacedrive）要求发布优先于加深。
