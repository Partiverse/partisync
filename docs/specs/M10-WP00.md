| WP | 主题 | 状态/交付 |
|---|---|---|

| M10-WP02 | **记忆面板 UX 深化** | 排序/筛选/复制/时间展示/详情联动（T02 面板已交付基础上做可用性迭代）；编辑/删除 UI 仍挂 tombstone（M10-WP04 前置） |
| M10-WP03 | **桌面深耕二期 + T04 GUI 承接** | M9-WP03-T04 GUI 三态验收 + 全 tab 巡检（人工件窗口）+ 浏览/详情 UX 迭代；沿 M8-WP05/M9-WP03 判例（截图归档硬性规则） |
| M10-WP04 | **记忆层二期**（α2 后置） | tombstone（update/delete/GC）+ CAS 内容重组清偿（NB5）+ 语义向量检索条件评估（新依赖走 ADR） |

| M10-WP06 | **发布节奏** | v0.1.0-beta 已发布（2026-10-05，M9-WP06 执行）；rc/0.2.0 口径拍板 + drop-caches 复测窗口 + 示例扩展生产钥签名窗口 |
