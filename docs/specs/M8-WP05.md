## 1. 动机

G2 薄面（`ui/` 仅 3 文件 321 行）与引擎能力严重不匹配：检索只有 BM25
（hybrid/转写后端已交付未接线）、浏览无详情（CAS/转写产物不可见）、
**同步状态零呈现**（desktop 不依赖 partisync-sync）。前端提速指令
（2026-09-29）要求功能落地步调加快——本 WP 把三大主界面立起来，旗舰
功能 = **文件域语义检索**（调研报告确认的差异化空位：Ente/Immich 只
做了照片域）。

不做则引擎对终端用户持续不可见，桌面壳停留在演示骨架。

## 2. 契约（草稿级，批准即冻结；映射关系以 function-map §4 裁决为准）

### 2.1 T1 语义检索旗舰（search tab 旗舰化）

- 新 IPC `search_hybrid {q, limit?, top_k?}` →
  `IndexEngine::hybrid_search`（await）；响应归一 SearchHit 形 +
  `mode: "hybrid"` 字段（N3）；
- **向量引擎独立懒加载**（独立 OnceCell，首次切语义开关才加载；不在
  启动路径——N1，冷启动预算硬线不放宽）；
- 前端：search tab 增「BM25｜语义」开关，结果渲染统一（零前端分支），
  命中带 mode 标注。

### 2.2 T2 浏览详情 + 转写检索

- 新 IPC `asset_detail {content_id}` → graph 行 + cas 引用统计；
- 浏览行点击详情面板（内容身份全量/CAS 引用/转写预览——转写经
  `mcp_call asset_read`，N5 双通道裁决）；
- search tab 转写开关 → `search {include_transcript:true}`（N4，零
  后端增量）。

### 2.3 T3 同步状态界面（新 tab）

- 新只读依赖 `partisync-sync`（**不引入写路径/网络面**，Hub/iroh 不进
  desktop 进程——N2）；
- 新 IPC `sync_stats`（SyncStats：applied/skipped/conflicts）+
  `sync_recent`（oplog/journal 尾部最近活动）；
- 前端新 tab「同步」：统计卡 + 最近活动表；纳入 5s 轮询模式（H3）。

### 2.4 T4 扩展面板增强

- ext_list 载荷的 manifest capabilities 展示（G2）；调用历史（会话内
  最近 N 次入参/出参，前端态）。

### 2.5 横切约束

- 所有新 IPC 沿用 `{kind,msg}` 错误分类学（H1）与 mock_builder 空态
  测试模板（N6）；
- 高频读走直接 IPC、能力聚合走 mcp_call（N5 双通道裁决）；
- **GUI 实操验收**（AGENTS.md 硬规则）：每任务 PR 前 AI 实际操控验证
  + 截图归档 `docs/screenshots/`；
- **视觉实现以设计规范为准**（docs/design/M8-WP05-design.md：tokens/
  wireframe/指纹色派生），高保真原型三页（检索/浏览/同步）已经用户
  审批材料确认。

## 6. 风险与开放问题

| # | 风险 | 概率 | 影响 | 处置 |
|---|------|------|------|------|
| R1 | 向量模型懒加载首查延迟（模型加载秒级） | 高 | 中 | 首查加载态 UI 明示；预热点选（模型常驻后零成本） |
| R2 | sync 只读依赖引入传递面（二进制膨胀） | 中 | 低 | T3 落地时 cargo tree 核对增量，超预期走裁剪（feature 门） |
| R3 | GUI 实操在 headless CI 不可自动化 | 高 | 低 | GUI 验证为本机人工流程（AGENTS.md 规则），CI 只跑单测/门禁 |
| R4 | 与并行会话工作树冲突 | 中 | 中 | 独立 worktree（multi-agent-protocol §3） |
| R5 | HybridResult→SearchHit 归一损失语义（score 口径） | 中 | 低 | mode 字段标注 + T1 测试断言两通道结构一致 |
