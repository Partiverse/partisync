# SPEC: M-1-WP02 —— CI 门禁流水线

版本: 1.0 · 状态: 批准 · 关联: ADR-0000、执行方案 §3.1/§4 · 上游: 执行方案 §6.0
负责人: @lead · 批准日期: 2026-09-18

## 动机

铁律 5「门禁前置」的机械化。无 CI 即无门禁，SOP 的 G2 无法执行。

## 契约

GitHub Actions 工作流 `ci.yml`，包含：

| job | 内容 | 阻断 |
|---|---|---|
| fmt | `cargo fmt --all --check` | 是 |
| clippy | `cargo clippy --workspace --all-targets -- -D warnings` | 是 |
| test | `cargo test --workspace`（ubuntu + macos 矩阵） | 是 |
| deny | cargo-deny（许可证/通告/重复版本） | 是 |
| task-ids | `scripts/check-task-ids.sh <base> <head>`：PR 内全部非合并提交须携带合规 Task-ID trailer（铁律 2） | 是（仅 PR） |

工具链版本与 rust-toolchain.toml 一致（1.93.1）。本地等效检查：`scripts/check-task-ids.sh` 可独立运行。

## 验收标准

- [ ] ci.yml 语法有效（actionlint 级人工核对）且 job 划分符合上表
- [ ] check-task-ids.sh 对「缺 Task-ID 的提交」退出非零并输出提交主题；对合规区间输出 OK
- [ ] 门禁阈值改动须 ADR 的规则已写入 ci.yml 头部注释

## 非目标

覆盖率差值、基准差值、模糊、变异、夜间套件（M0 起随基建补齐，登记为债务）。

## 涉及文件清单

.github/workflows/ci.yml、scripts/check-task-ids.sh
