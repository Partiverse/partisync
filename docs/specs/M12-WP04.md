## 2. 轮 1 契约：P3 UX 硬化

### 2.1 help 基建（T03）

- `partisync --help` / `partisync help`：总览（16 动词一行一条 + 全局
  旗标），exit 0；
- `partisync help <verb>` 与 `partisync <verb> --help`：动词级 usage
  （位置参数 + 全部旗标 + 一句话语义），exit 0；文案与实际解析**逐一
  对应**（旗标表驱动，禁止手抄漂移——usage 文案数据与解析器共用同一
  张旗标表）；
- 裸 `partisync <verb>` 缺必选参数：打印**该动词** usage（非整块），
  exit 2；
- 未知动词：总览 usage，exit 2（现状行为保持）。

### 2.2 未知 flag 显式报错（T04）

`flag_value` 位置扫描升级为白名单校验：各动词声明旗标集，出现未登记
`--xxx` → stderr 报错（点名 flag + 指引 `partisync help <verb>`），
exit 2。**零合法调用行为变化**（旗标顺序无关性维持）。

### 2.3 T08 ⑩ 微债清偿（T05）

- `partisync-fuse`：usage 文案与实际位置参数/旗标解析对齐（盘点实测
  不符项逐一修正）；
- `hub-demo-web`：`--help`/`-h` → usage + exit 0（不再直起服务）；
  未知 flag 同样显式报错 exit 2。

### 2.4 明确不做

**不引入 clap**（16 动词手写分发已稳定；引 clap = 新顶层依赖需 ADR，
收益不抵——help 基建手写小而确定）。

## 3. 轮 1 验收标准（可执行）

- [ ] `partisync --help`/`help`/`help <verb>`/`<verb> --help` 四形态输出与行为断言（单测快照：动词集与盘点 16 动词逐一对应，零遗漏）；
- [ ] usage 文案与解析器同源（旗标表单一数据源的结构性断言/测试，防手抄漂移）；
- [ ] 未知 flag：`partisync ls --dbb x` → exit 2 + stderr 点名 `--dbb`（单测断言）；全部 16 动词旗标集登记零遗漏（漏登记 = 合法调用被误伤，测试覆盖每动词至少一条合法调用回归）；
- [ ] `partisync-fuse` usage 与解析一致（对照单测/人工实录归档）；`hub-demo-web --help` exit 0 且不监听端口（集成测试：子进程 spawn 断言退出码与输出）；
- [ ] 零新增顶层依赖、零 unsafe、公共库面（lib.rs 导出）零变更（纯 bin 面改动）；
- [ ] 三门禁绿；现有合法调用行为回归绿（全动词冒烟，沿 T08 域矩阵口径抽测）。

## 4. 轮 2 契约：P1 机器可读契约层（T08）

### 4.1 `--json` 增量旗标（全动词）

- 每动词接受 `--json`：**成功**时 stdout 输出该动词结果的单行 compact
  JSON（UTF-8，snake_case 键，结构体字段序稳定=版本内不破坏承诺）；
  **失败**时 stdout 恒空、错误走 stderr 人读中文 + 非零退出码（JSON
  面与错误面互斥，不产半态）；
- 长驻/作业型动词（index/resume/index-remote/watch/ui/event-drain/
  sidecar-run）：`--json` 仅改变**启动摘要**输出形态（job id/配置回显
  一行 JSON），运行期流式进度维持 stderr 人读——诚实边界，进度流结构
  化不在本合同；
- 默认（无 `--json`）人读输出**逐字节不变**（非 breaking）。

### 4.2 退出码契约统一 + 文档化

- 契约文档 `docs/CLI-CONTRACT.md`（新）：0 = 成功（含空结果）/ 1 = 运
  行错误 / 2 = 用法错误（含未知动词、未知 flag、缺必选参数）/ 130 =
  SIGINT 中断；每动词一节（flag 表 + JSON 形状表 + 退出码），随实施
  PR 落档；
- **行为统一两处**（显式登记的行为变化，v0.3.0 线内一次性完成）：
  `ls` 空结果 1 → **0**（空集=成功，取 `find` 口径）；`watch` Ctrl-C
  0 → **130**。

### 4.3 轮 2 验收标准（可执行）

- [ ] 16 动词逐一 `--json` 快照测试（固定 fixture → 输出 JSON 可被 serde 回读 + 键集断言；形状表随 docs/CLI-CONTRACT.md 与测试同源）；
- [ ] 失败路径零 stdout 断言（非法输入 → stderr 非空 + exit≥1 + stdout 空）；
- [ ] 默认输出逐字节不变（同 fixture 有/无 `--json` 双跑对照，人读面 diff 为空）；
- [ ] 退出码契约测试表（`ls` 空=0 / `find` 空=0 / 用法错=2 / watch 中断=130 逐一断言）+ docs/CLI-CONTRACT.md 落档；
- [ ] 零新增顶层依赖（serde/serde_json 为 workspace 既有 pin，crate 级新边随实施 PR 登记）；三门禁绿。

## 5. 轮 3 契约：P2 partisd 客户端打通（T10，ADR-0036 已接受）

通道面决策见 **ADR-0036**（已接受，2026-10-12）：CLI 复用 rmcp 3.4.0
`client` + `transport-streamable-http-client` 特性（零新顶层依赖，新
边 CLI→rmcp 已登记）；`status`/`ping` = pidfile + TcpStream 探活（零依
赖）；`stop` = shell-out `kill <pid>`（unix-only 登记）。动词契约：

- `partisync partisd status`：pidfile 解析 + 进程存活 + TCP 可达 +
  工具面计数（`tools/list`）→ 人读/`--json`；
- `partisync partisd ping`：轻探活（连接 + initialize 往返），exit 0/1；
- `partisync partisd stop`：SIGTERM 经 `kill`（优雅退出沿 ADR-0032）；
- `search --daemon`（或自动探测：7650 可达即走守护进程）：hybrid 三腿
  走 loopback MCP，不可达回落直连现行为（stderr 注明回落）。

验收：四动词单测（spawn 真 partisd 于临时端口）+ `search` 双路径对照
（daemon 在位/缺席）+ 实施 PR 附 `cargo deny check` + `cargo audit` 输
出（ADR-0036 后果节义务）。

## 6. 轮 4 契约：P4 doctor（T09）

`partisync doctor` 环境体检（ga 式 DX 仓内化），体检项六类：

| 项 | 检查 | 依赖 |
|---|---|---|
| db | graph store 打开 + schema 版本回读 | 直连 |
| cas | 目录存在 + 可写探针 | 直连 |
| index | 只读打开 + 文档计数 | P24 只读路径 |
| partisd | pidfile + TCP 探活 + 工具面计数 | 轮 3 客户端（缺席项=降级显示「未运行」，非错误） |
| 扩展 | `~/.partisync/extensions/` 扫描：三件套配对 + minisig 在位（WP03 约定，孤儿/缺签显式点名） | 零依赖 |
| 模型缓存 | fastembed 缓存 presence（graph-embed 可用性预告；缺失=信息项非错误） | ai 层 |

输出：人读体检表 + `--json`（依赖轮 2 契约基建，故轮 4 排轮 2 后）；
全绿 exit 0，任一 fail 级项 exit 1（降级/信息项不影响退出码）。

轮 4 验收：各体检项单测（临时目录注入，正/反两态）+ `doctor --json` 快
照 + 缺席降级语义断言（partisd 未运行 = 信息项 + exit 0）。
