## 工具规格

### 1. `asset_search`

**描述**：以自然语言查询资产，返回排序结果列表。

**输入**：
```json
{
  "query": "string",           // 自然语言查询
  "limit": 20,                 // 默认 20，max 100
  "vector_kind": "auto",       // "auto" | "text" | "image"
  "filters": {
    "content_ids": ["..."],    // 可选，按 ID 精确过滤
    "tags": ["..."],           // 可选，按标签过滤
    "mime_kind": "image/*",     // 可选，MIME 类型前缀
    "date_from_ns": 0,         // 可选，时间范围
    "date_to_ns": 0
  },
  "include_transcript": true   // 是否包含转写文本
}
```

**输出**：
```json
{
  "hits": [
    {
      "content_id": "...",
      "score": 0.95,
      "highlights": ["...OCR snippet...", "...filename..."],
      "mime_kind": "image/jpeg",
      "updated_ns": 1234567890
    }
  ],
  "total": 150,
  "timing_ms": 42
}
```

**实现**：调用 `IndexEngine::hybrid_search`，将 `SearchFilters` 映射为 WP02 `SearchFilters`。

### 2. `asset_read`

**描述**：读取资产元数据（不返回文件内容，仅元数据）。

**输入**：
```json
{
  "content_id": "string"
}
```

**输出**：
```json
{
  "content_id": "...",
  "entry_id": "...",
  "name": "IMG_1234.jpg",
  "mime_kind": "image/jpeg",
  "size_bytes": 1234567,
  "created_ns": 1234567890,
  "updated_ns": 1234567890,
  "tags": ["vacation", "2024"],
  "sidecar_stages": {
    "thumbnail": "done",
    "exif": "done",
    "ocr": "done",
    "transcribe": "skipped",
    "embed": "done"
  },
  "embedding": {
    "text_dim": 768,
    "text_model": "bge-m3",
    "image_dim": 512,
    "image_model": "clip-vit-b32"
  }
}
```

**实现**：查询 `graph.content` + `graph.sidecar_items` 表，聚合 stages 状态。

### 3. `asset_organize`

**描述**：预览资产归类操作（不执行），返回待确认的操作计划。

**输入**：
```json
{
  "operations": [
    {
      "content_id": "...",
      "action": "add_tag" | "remove_tag" | "set_tag" | "delete",
      "value": "vacation"
    }
  ],
  "preview_only": true
}
```

**输出**：
```json
{
  "planned": [
    {
      "content_id": "...",
      "action": "add_tag",
      "value": "vacation",
      "effect": "tag 'vacation' will be added to asset"
    }
  ],
  "transaction_id": "txn_abc123",   // preview_only=false 时返回
  "confirm_url": "/api/assets/confirm/txn_abc123"
}
```

**实现**：事务写入 `graph.asset_txn` 表（status=pending），返回 txn_id；confirm 调用正式提交。

### 4. `dataset_export`

**描述**：导出资产集合为 manifest（JSON Lines 格式），包含元数据 + 嵌入向量。

**输入**：
```json
{
  "content_ids": ["...", "..."],   // 留空表示全量
  "filter": {
    "tags": ["..."],
    "mime_kind": "image/*"
  },
  "include_vectors": true,           // 是否包含嵌入向量
  "format": "jsonl"                // "jsonl" | "json"（目前仅 jsonl）
}
```

**输出**：
```json
{
  "manifest_path": "/path/to/export_20240922_123456.jsonl",
  "record_count": 42,
  "total_bytes": 12345678,
  "expires_at_ns": 1234567890      // 24h 后过期清理
}
```

**实现**：流式写入临时文件，manifest 记录 content_id + 元数据 + 可选向量路径引用。

### 5. `job_status`

**描述**：查询 Sidecar 管线作业状态。

**输入**：
```json
{
  "job_id": "..."                   // 留空返回最近 N 个
}
```

**输出**：
```json
{
  "jobs": [
    {
      "job_id": "...",
      "content_id": "...",
      "pipeline": "thumb→exif→ocr→transcribe→embed",
      "status": "running" | "done" | "failed",
      "current_stage": "ocr",
      "progress_pct": 60,
      "started_at_ns": 1234567890,
      "updated_at_ns": 1234567890,
      "error": null
    }
  ]
}
```

**实现**：查询 `jobs.jobs` 表（WP01 产物），映射 `run_state` → `status`。

## MCP Server 设计

### 传输层

- **Stdio 传输**（RMCP 2026-07-28 stateless 推荐）：进程通过 stdin/stdout 读写 JSON-RPC 2.0 消息
- 服务入口：`partisync-mcp` binary（或 `partisync-cli mcp` 子命令）
- 不维护连接状态——每次调用自包含

### 请求路由

```
JSON-RPC Request
  → method: "tools/list"         → 返回工具清单
  → method: "tools/call"         → 分发到具体工具处理器
      → name: "asset_search"    → IndexEngine::hybrid_search
      → name: "asset_read"      → GraphStore + SidecarStore 聚合
      → name: "asset_organize"  → AssetTxn 事务写入
      → name: "dataset_export"  → ManifestWriter 流式导出
      → name: "job_status"       → JobsStore 查询
```

### 依赖方向

```
partisync-gateway (MCP server crate)
  → partisync-index  (hybrid_search API)
  → partisync-graph  (content / sidecar_items / tags / jobs)
  → partisync-ai     (SidecarStore / Pipeline)
```
