## 1. 动机

M8 交付后挂载写只落本地：WAL（`<backing>/.partisync-writeback/wal.jsonl`，
P16 先日志后应用）+ overlay，**不进 graph、不进 oplog、不参与同步**——
单机孤岛面（M9-roadmap-proposal N1，定位级缺口）。现状双重缺失（实测）：

1. 无任何生产进程把 WAL 写折叠为 EventRecord 喂 sync 侧（EventRecord
   构造仅存在于 wiring_e2e 测试）；CLI `partisync watch` 只写 graph
   journal，不写 oplog；`session::push/bisync` 生产调用方为零（仅测试）。
2. 无任何进程驱动 push/bisync 循环。

不接线则 FUSE 二期写回语义与同步产品定位脱节；watermark 统计债 F1
（sync_stats 由 `pending_oplog` 现算，push ACK trim 后归零）同源，随本
WP 一并清偿。

## 2. 契约

### 2.1 装配层（gateway `partifuse --graph <dir>`）

- gateway bin `partisync-fuse` 新增 `--graph <dir>` 选项：装配 graph
  store + sync 循环与既有 mount 同进程运行；缺省（无 `--graph`）行为
  不变（纯挂载，兼容 M8 语义与既有探针）。
- 事件折叠：WAL `execute()` 成功后的 `WriteBackOp`（Unlink/Rmdir/
  Rename/Replace）折叠为 `EventRecord`（`partisync-sync/src/event.rs`
  现有类型），继承 wiring_e2e 契约：`provider="partifuse"`、path 带前导
  `/`、**Rename 的 Created 事件必带 size**（叶哈希判例，wiring_e2e
  `:18-22`）。mkdir/create 新文件直落 backing 者经同层 capture 上报
  （`capture::record_entry_upsert/remove`）。
- 应用路径：EventRecord → `GraphApplier`（图应用，父目录链自动建）→
  `capture` 写 oplog（origin=本设备）→ 同进程 bisync tick 驱动
  `session::bisync`（周期可配，默认 5s；`push_opts` max-delete 阈值
  沿现有默认）→ ACK trim → `note_applied` 水位更新。
- 同根校验：`--graph <dir>` 的 graph 索引根必须与 FUSE backing 同根，
  装配期校验失败拒绝启动（wiring_e2e `:161-168` 判据生产化）。

### 2.2 统计口径（F1 清偿）

- `sync_stats`（desktop ipc）的 `devices` / `last_sync_ns` 改由持久
  `sync_watermark` 表（`store::watermarks()`，只增不被 trim）派生；
  `pending_oplog` 保留为待推送计数。push ACK trim 后统计不再归零。

### 2.3 冲突语义（SEMANTICS 修订，走 ADR-0026 修订登记）

- 挂载路径本地写 vs 远端并发改：entry 域沿 P11「保留两者 + 血缘落档」
  （`.conflict-*` 后缀口径），装配层把冲突结果折叠为新事件回灌；
  共享域（tag）HLC LWW 沿既有（`skipped_lww` 计数不变）。
- 回环防护：oplog 行 origin 标记 + `skipped_self_origin` 剪枝不变；
  本地 capture 回填水位语义（本地写恒胜）沿 `capture.rs` 现行机制。

### 2.4 新不变量候选（P19，随实现走 partisync-property-registry 登记）

- **P19（候选）挂载写同步收敛**：挂载写经装配层进入 graph/oplog 后，
  (a) 双端 bisync 不动点后 Merkle 同根；(b) 本设备事件不经远端回流
  （origin 剪枝）；(c) WAL crash 重放（P8/P16）后 oplog 与 graph 一致、
  不重放产生重复 oplog 行。登记先于任何测试代码编写（铁律 4）。

## 3. 验收标准（可执行）

- [ ] e2e 探针（环境门控，Linux 容器真挂载，沿 M8 探针判例）：挂载点
      写文件 → tick 周期内第二端（第二 graph）bisync 后可见；两端
      Merkle 同根（P6/P19-a；继承 wiring_e2e 同根校验）
- [ ] unlink/rmdir/rename 经 WAL 路径写 → 事件折叠正确（前导 `/`、
      Rename 带 size）→ 远端应用后同名消失/迁移（P16 × P19-a）
- [ ] crash 注入：WAL 未 apply 崩溃 → 重放后 backing 一致（P8/P16）
      且 oplog 无重复行（P19-c）
- [ ] 回环探针：双端互连时本设备事件不回流（`skipped_self_origin`
      计数增长，P19-b）
- [ ] 冲突探针：同路径双端并发写 → 两者皆可寻址 + 血缘落档（P11）
- [ ] F1 回归：push ACK trim 后 `sync_stats` devices/last_sync 不归零
      （watermark 派生）；单测覆盖 desktop ipc 视图
- [ ] 无 `--graph` 时既有 M8 探针（probe_mount/probe ①–⑨/wiring_e2e
      现有段）全绿零回归（P15）
- [ ] fmt/clippy/test 三件套全绿；新依赖零引入（gateway 仅升
      partisync-sync/graph 为正式 path 依赖，无外部新依赖）
