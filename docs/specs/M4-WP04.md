## 裁定总览

### 1. iroh-blobs fs-store 冲突解决方案

**问题**：`iroh-blobs 0.103.0` 的 `fs-store` 条件编译路径用 `tokio::task::block_in_place`（需 tokio `blocking` feature），workspace tokio 1.53 不满足。

**决策**：hub 层**绕过** `iroh-blobs` 的 `store` 子模块，直接使用：
- `iroh::Endpoint`（主 crate，无 fs-store 依赖）
- `iroh_blobs::get::fsm`（状态机，用于 download）
- `iroh_blobs::protocol::ALPN`（协议常量）
- hub 自有 CAS `ChunkStore` 实现存储（不依赖 `iroh_blobs::store::Store`）

**理由**：`iroh-blobs` 的 `store` 是可选附件，hub 已有 `partisync-cas` 提供块存储，无需再引入一个 store。

### 2. Upload 路径（设备→hub）

```
设备侧                          Hub 侧
  │                               │
  │  Endpoint::connect(hub_addr, ALPN)
  ├───────────────────────────────▶│
  │                               │
  │  GET /iroh-blobs/1 (BLAKE3 hash request)
  │  ────────────────────────────▶│  Endpoint::accept() → Incoming → Accepting
  │                               │  Router 在后台 accept（ALPN=b"/iroh-bytes/4"）
  │  Stream: chunk[0..X]          │  handle_connection 处理
  │  Stream: chunk[X..Y]          │    → 设备 push blob 数据
  │  ...                          │    → 每 chunk 调用 ChunkSink::put_chunk
  │                               │
  │  UploadAck ←──────────────────│  完整 blob 写入 CAS 后
```

关键 API（来自 `iroh 1.2.0` + `iroh-blobs 0.103.0`）：
```rust
// hub 侧建节点（iroh_channel.rs）
use iroh::{Endpoint, endpoint::presets};
use iroh_blobs::protocol::ALPN;

let endpoint = Endpoint::bind(presets::N0).await?;
endpoint.online().await; // 等待 relay 连接就绪
let addr = endpoint.addr(); // → EndpointAddr（可分享给设备）

// Router accept（hub 后台任务）
let blobs = BlobsProtocol::new(&store, None); // store = CAS ChunkStore 实现
let router = Router::builder(endpoint)
    .accept(ALPN, blobs)  // b"/iroh-bytes/4"
    .spawn();
```

### 3. Download 路径（hub→设备）

```
Hub 侧                          设备侧
  │                               │
  │  设备发送 WantHashes { [hash0, ...] }
  │  ─────────────────────────────▶│
  │                               │
  │  收到 WantHashes
  │   → ChunkPlan 差分（已有实现）
  │   → 对每个 Need 块：
  │     conn = Endpoint::connect(device_addr, ALPN).await?
  │     request = GetRequest::blob(hash)
  │     state = fsm::start(conn, request, RequestCounters::default())
  │     // 驱动状态机 → AtBlobContent → drain() → 设备接收
  │  ◀──────────────────────────────│
  │                               │
  │  设备 BLAKE3 验签（窗口级）
  │  验签失败 → NACK + 重发请求
```

关键 API：
```rust
use iroh_blobs::{get::fsm, protocol::GetRequest};

let conn = endpoint.connect(peer_addr, ALPN).await?;
let request = GetRequest::blob(hash);
let counters = fsm::RequestCounters::default();
let state = fsm::start(conn, request, counters);

let mut at = state.next().await?; // AtInitial → AtConnected
loop {
    match at {
        fsm::AtConnected::StartRoot(start) => {
            let header = start.next().await?;
            let (content, _size) = header.next().await?;
            let end = content.drain().await?; // 流式写入设备
            at = end.next().await?;
        }
        fsm::AtConnected::Closing(c) => {
            let _stats = c.next().await?;
            break;
        }
        // ... StartChild 同理
    }
}
```

### 4. HubIrohKeyspace 实现

hub 的 iroh 节点密钥持久化到 fjall keyspace `h-iroh-node`：
```rust
// trait 定义在 iroh_channel.rs
pub trait HubIrohKeyspace: Send + Sync {
    fn get_node_sk(&self) -> Result<Option<String>, PartisyError>;
    fn put_node_sk(&self, sk: &str) -> Result<(), PartisyError>;
}

// 实现：raft_store 或 registry 模块持有一个 fjall::Keyspace
// 节点私钥 = Ed25519 SecretKey（来自 hub master key 派生，ADR-0010）
```

### 5. 中继语义（ADR-0015 裁定 2）

- hub 节点开启 relay：`presets::N0` 已含 relay 支持
- hub 作为 ALWAYS reachable endpoint：设备 NAT 穿透失败自动走 iroh relay
- relay 费用由 hub 运营方承担（iroh 1.x 定价模型待 M4 进场地确认）

## 契约

### iroh 通道模块边界

```
partisync-hub
  ├── iroh_channel.rs    # HubIrohNode 门面（new/run/node_addr）
  │                      # + HubIrohKeyspace trait
  └── ChunkSink/ChunkSource (via partisync-transfer)

partisync-transfer
  └── iroh_blobs.rs      # ChunkSink/ChunkSource trait 定义
                         # + IrohBlobsExecutor/IrohBlobsListener 桩

partisync-cas
  └── ChunkStore         # 实现 ChunkSink（write）+ ChunkSource（read）
```

iroh crate 类型（`Endpoint`/`EndpointAddr`/`Connection`）**仅在** `iroh_channel.rs` 内部可见，不穿透 trait 边界。
