### 2.4 降级语义（推荐 fail-open + 显式降级标记，标注待评审）

- **推荐：fail-open**——嵌入器缺失/初始化失败/向量索引缺失时，
  `memory_search` 正常返回 BM25 通道结果，响应载荷**显式携带降级标记**
  （如 `degraded: "vector_unavailable"`），不静默、不报错。
- 依据：①既有判例链一致——FTS 不可用降 LIKE（store.rs:2533，fail-open）
  ；CLI hybrid 需嵌入时回退 BM25 且 stderr 显式提示（main.rs:955-965，
  fail-open + 显式提示）；评估件 §4 落锤项 ③「方案 C 暴力扫作冷启动/
  回退（沿 FTS→LIKE 降级判例，M10-WP04-memory-vector-eval.md:243）」
  **方向一致但回退机制不同**：评估件原文 = 向量暴力扫作回退，本节
  推荐 = fail-open 回退现有 BM25 通道（FTS5+LIKE）——该机制偏离已
  登记 §6-Q2，随 ADR 评审显式处置，本节不代裁；②检索为只读查询面，
  fail-closed 将模型故障放大为检索全不可用，
  无安全收益；③**与 2.2 初始化 fail-fast 不矛盾**：init 期模型维度
  异常 = 配置错误必须暴露；运行期模型/索引缺失 = 环境状态，降级保可用。
- **标注待评审**：fail-open vs fail-closed 二选一在 ADR 评审拍板
  （§6-Q2）；本 SPEC 按 fail-open 起草，评审翻转则本节与 2.5 响应
  契约同步改写，验收 3.5 相应调整。

### 2.5 检索语义边界与公共面

- `memory_search` MCP 工具新增**可选参数**（如 `mode: "hybrid"`），
  开启时 = BM25 Top-N + 向量近邻 Top-N → RRF 融合（k=60，对齐
  crates/partisync-index/src/search/hybrid.rs:25 判例；graph 本地实现
  RRF 融合式，不依赖 index crate——
  与 hybrid.rs 的重复 ~20 行为已知债务，§6-Q6）；无该参数的请求
  **工具 schema 与响应载荷形状与现状一致**（增量可选参数，沿
  M10-WP04-memory-vector-eval.md:245「memory_search 可选参数增量」
  判定；instructions 文本同步 mcp.rs:550-553）。
- 向量通道不改变 BM25 通道打分/排序/高亮；融合仅作用于返回排序，
  命中叶仍是 memory 行（memory_id 回表），不引入新实体。
- **写入时机**：嵌入异步伴生，不进 memory_write 写事务
  （M10-WP04-memory-vector-eval.md:246）；T04 判例 118076 叶 31s 批量

  存量回填走批量回填器（§5）。

### 2.6 存储代价预算（类比 WP04 stored 口径，纸面推荐值 + bench 钉实）

  评估件 §5；10× 余量覆盖模型加载/批调度；超线 → bench 报告归档评审）；
