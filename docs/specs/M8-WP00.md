## 0. 动机

M7 关账（`928d55f`，2026-10-01）后四 WP 全闭合：WASM 扩展实施（P13/P14
探针面）、AI 安全复核（M2-D1/OSCP Conditional Pass）、SMB/FUSE 桥接评估
（ADR-0026 产出）、M8+ 前瞻计划（WP04 增补，提案已批准 v1.0）。M8-WP01
FUSE 一期已在 M8 开局夜间窗口交付并验收（T01–T03，PR #54–#57，一期验收
确认 `0137d1e`）。

前瞻计划盘点的三空白构成本总纲的问题陈述：**G1 对外发布零实跑**（全仓
0 git tag、无 release workflow、G4 签名+SBOM 从未执行——可分发版本是
一切企业/生态/分发叙事的前提）；**G4/G5 治理与一致性地基**（Hub 无审计
日志/配额；RFC M3-WP02 §8 Hub-raft 业务接线为最老未结移交债）；**G6/G7
扩展信任**留 M9、M8 只做 epoch/fuel 终止保障小项。不解决则产品停在
「引擎能力完整但无可分发版本、无治理面、线性一致承诺与实现脱节」的
状态，竞争窗口（Spacedrive V2 alpha 期、MCP 签名分发留白）流失。
