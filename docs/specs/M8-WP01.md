### 2.2 语义面（P15 转正）

沿 `partisync-fuse-spike/SEMANTICS.md`，一期冻结：

| 操作 | 语义 |
|---|---|
| readdir / lookup / getattr | 后备目录实时视图 |
| read（随机读） | 已存在文件任意 offset，`O_RDONLY` |
| create（新文件） | `O_CREAT\|O_EXCL` 强制；存在即 EEXIST |
| write（顺序追加） | offset == 当前长度，跳写 EINVAL；release 后不可再写 |
| 拒绝面 | unlink/rmdir/rename/mkdir/mknod/symlink/setattr→EPERM；已存在文件写打开→EACCES；**拒绝先于破坏性效果** |

### 2.3 权限模型（ADR-0026 前置条件 1 处置）

- FUSE 层**关闭 `DefaultPermissions`**，由宿主自管权限判定（spike 形态）：
  attr 统一报告挂载进程 uid/gid + `0o755/0o644`（与 Linux 默认 allow
  other 读一致）；写类操作在 FUSE 层前置拒绝（§2.3 拒绝面），
  **内核不做二次权限过滤**；
- **宿主权限责任面扩大**记 R2 评审项（ADR-0026 §后果已预登记）：评审须
  覆盖「谁能挂载 / 挂载点文件权限 / 多用户机器的暴露面」三问；
- Samba 桥接属主映射：不在一期（ADR-0026 前置条件 4，维持可选）。

### 2.4 数据面

- 一期挂载**本地目录视图**（backing dir 透传，与 spike 同构）——CAS 内容
  寻址视图（`/by-hash/<blake3>` 只读命名空间）为二期项；
- 读路径直读 backing（页缓存自然生效）；写路径 append 直落 + flush 无
  缓存语义（spike 实测形态）。
