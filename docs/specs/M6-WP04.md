# SPEC: M6-WP04 —— WASM 扩展系统评估（选型 spike + ADR，实施留 M7+）

版本: 0.1 · 状态: 批准（2026-09-28 用户拍板）· 关联: ADR-0025（草稿）· 上游: 执行方案 §6.7、调研方案 §M6+（line 595）、ADR-0024
负责人: @lead · 批准人: @lead · 批准日期: 2026-09-28

## 1. 动机

M6 §6.7 滚动产品化四主题中，「Tauri 2 桌面壳」已随 M6-WP03 闭合；
本 WP 处理第二主题「WASM 扩展系统评估（学 Spacedrive 沙箱）」。
PartiSync 的长期竞争位（调研方案 §结论先行）依赖 AI 原生扩展面：
第三方/内部工具以沙箱组件形态接入资产图谱，而不必进 workspace
依赖树或触碰 R2 钉子清单。参照系 Spacedrive 的 WASM 扩展至今
（2026-09）仍是 roadmap 未落地项——无现成范式可抄，需要一份
可复核的选型证据，而不是直接拍板。

不解决的代价：

1. 扩展能力长期缺位，每次新工具需求都走「新 MCP tool 进
   partisync-gateway + 全门禁」重路径，慢且膨胀核心；
2. ADR-0024 留的 Tauri IPC capability 边界（7 commands +
   mcp_call 侧车）悬空无消费者，脚手架价值无法兑现；
3. M7+ 若被迫仓促选型，可能引入与 1.94 toolchain / deny 策略
   冲突的重量级依赖。

**本 WP 交付评估与选型决策，不交付生产扩展运行时**（实施留
M7+ 单独 WP/SPEC）。

## 2. 契约（评估对象与判定基准）

### 2.1 窄核心定位（评估前提，学 Spacedrive V1 死因教训）

第一版扩展形态锁定为：**「沙箱化的 MCP tool」**——一个 wasm
component 实现既有 MCP 工具语义（JSON 入参 → JSON 出参），经
宿主加载后可被 `partisync-mcp` 工具面与桌面壳 `mcp_call` IPC
（M6-WP03 §2.3）无差别调用。评估候选方案时只问「能否以最小
宿主面实现该形态」。

### 2.2 候选方案（评估矩阵行）

| 候选 | 宿主依赖 | 评估焦点 |
|------|---------|---------|
| C1 wasmtime + WIT Component Model 直接嵌入 | `wasmtime`（顶层新依赖） | 依赖面最小化 vs host boilerplate；WASI 0.3（2026-06 落地）成熟度 |
| C2 Extism（建在 wasmtime 上） | `extism`（顶层新依赖） | PDK/宿主契约开箱即用 vs 额外依赖耦合层 |
| C3 Wassette 模式（wasm component 即 MCP tool） | 参考实现，不一定引依赖 | 与既有 MCP 工具面的语义对齐度；可借鉴设计而非引库 |

### 2.3 Spike 判定基准（全部可测量）

| 指标 | 基准 | 测法 |
|------|------|------|
| 宿主冷启动开销（加载 1 个 demo component） | < 100 ms | criterion，对比 `partisync-mcp` 侧车 spawn 基线 |
| 单次 tool call RTT | < 5 ms（10 KB JSON 往返） | criterion，同上基线 |
| 空载内存增量 | < 30 MB RSS | 进程前后差 |
| 沙箱默认面 | 无 FS / 无网络 / 无时钟（capability 默认全拒） | spike 探针：component 内尝试打开文件/连接必须失败 |
| MSRV 兼容 | Rust 1.94 toolchain 编译零警告 | `cargo clippy -D warnings` |
| 依赖卫生 | `cargo deny check` 通过；`cargo audit` 零新增未豁免 | 门禁命令 |

### 2.4 新不变量预告（登记路由）

沙箱能力隔离将构成新属性：**P13 扩展沙箱**——「未授予能力
(capability) 的 component 调用 FS/网络/时钟 API 必须返回拒绝
错误，且拒绝不泄露宿主路径/环境」。spike 期先以探针测试实现，
**正式登记走 partisync-property-registry，先于任何实施代码**。

## 4. 非目标

| 项 | 推迟至 | 理由 |
|----|--------|------|
| 扩展运行时生产化（进产品依赖图） | M7+ SPEC | 本 WP 只做评估与选型 |
| 扩展自定义数据模型随空间同步 | M7+ / 独立研究 WP | graph schema 演进大坑（Spacedrive 未交卷的领域），严禁混入选型期 |
| UI/前端扩展点（桌面壳插件面板） | M7+ | 先工具面后界面 |
| 扩展分发/签名/registry | M7+ 企业特性议题 | 供应链面，需独立威胁模型 |
| WASI 0.3 全依赖面（HTTP/sockets 等 hosted 能力） | M7+ | 第一版 capability 默认全拒 |
