## 动机

调研方案将「可信与溯源」列为 PartiSync 四大差异化能力之一：C2PA 2.4 规范已到生态
落地期（Adobe 工具链、OpenAI/Google 生成内容均开始携带 manifest），资产管理基建
需要**原生理解与保留**溯源清单。本 WP 把 C2PA 校验作为 Sidecar 管线第六环节
（调研方案 §6.3：「缩略图/EXIF → OCR → 转写 → 嵌入 → **C2PA 校验**」）：

- **摄取时校验**：内容入库跑管线时解析 C2PA manifest store，得出密码学完整性结论；
- **保留**：manifest store report JSON 落 `content.c2pa` 列（content 粒度——去重后
  一份内容只算一次、跨设备共享），原文件后续被改/删，溯源证据仍在库中。

## 现状锚点（诚实标注）

- `partisync-graph` content 表仅 `id/size/mime/kind`，**无 c2pa 列**（最新迁移 v14）
- `partisync-ai` 五 stage（thumbnail/exif/ocr/transcribe/embed）已实装，`Stage`
  trait 纯计算不持 Store，产物经 pipeline 落盘（`BlobSink`）
- **c2pa 依赖未引入**——本 WP T02 引入（ADR-0020）

## 契约（裁定）

### 裁定 1 · 依赖与版本

`c2pa = "=0.90.22"`, `default-features = false`, `features = ["rust_native_crypto"]`。

- 0.91.0 需 rustc ≥1.96 > 工具链钉子 1.94（升级工具链须独立 ADR + 全量回归，
  不在本 WP 范围）；0.90.22 需 1.88 ✅
- `rust_native_crypto` 纯 Rust 密码学路径（p256/p384/p521/rsa/ed25519-dalek，
  后者为 c2pa 必选依赖），**避开 openssl-sys 构建链与 4 套 http 客户端**
  （default = openssl + reqwest/ureq/wasi/wstd，全部关闭）
- 只读校验路径，不开 `file_io`/`pdf`/`add_thumbnails`/`fetch_remote_manifests`

### 裁定 2 · stage 语义

stage id `c2pa`，追加为 `STAGE_ORDER` 第 6 位；applicable = Image | Video | Audio。

执行（离线确定性 Context：`verify_trust=false`——信任链判定依赖信任列表获取，
属环境相关属性，不在「摄取校验」确定性义务内）：

| 结果 | sidecar 状态 | detail |
|---|---|---|
| 解析成功 → `validation_state()` | done | `state={valid\|invalid} label=<active_label> bytes=<n>` |
| `Err(JumbfNotFound)`（无 manifest） | done | `state=absent`（完成的校验结论，非失败非降级） |
| `Err(UnsupportedType)`（容器不支持） | skipped | `format-unsupported-by-c2pa` |
| 其他 Err | failed | 原因可查 |

**无效清单同样保留**（裁定 3 落列 + state=invalid 进 detail）——保留义务是证据学
义务，不因校验失败而放弃。

### 裁定 3 · 保留落点

manifest store report JSON（`Reader::json()`）写 `content.c2pa` TEXT 列
（schema v15 增量 `ALTER TABLE content ADD COLUMN c2pa TEXT`，与调研方案 §5.3
`c2pa JSON` 列对齐）。写入方 = pipeline（`Stage` trait 保持纯计算；c2pa stage
done 且有 blob 时由 pipeline 回写列）。blob 同时走 `BlobSink` 常规落盘通道
（产物形态与其他 stage 一致，artifact=文件引用）。

### 裁定 4 · 幂等与存量

同既有 stage 语义：done/skipped/failed 终态不重算；存量 content 重跑 sidecar
作业时 `ensure_enqueued`（INSERT OR IGNORE）幂等补入第 6 stage 行。

## 验收标准

- [ ] `default_stages()` 含 c2pa（第 6 位）；jobs 驱动 `stage IN (…)` 自动含新 stage
- [ ] 带 manifest 样本：stage done + `content.c2pa` 列写入可解析 JSON +
      detail `state=valid`（ES256 自签 fixture 经 `create_signer::from_keys` 生成）
- [ ] 无 manifest 样本：done + `state=absent`，c2pa 列保持 NULL
- [ ] text/plain：skipped(not-applicable)，不进入 c2pa 解析
- [ ] 篡改样本（manifest 后改字节）：state=invalid 且清单仍被保留
- [ ] 幂等：二次 run 不改写终态行
- [ ] gateway `asset_read` 输出 `sidecar_stages.c2pa` 字段（增量 JSON 字段）
- [ ] fmt/clippy(-D warnings)/test 全绿；cargo deny 四段通过（c2pa 进场）
- [ ] 追溯：每 commit 挂 M4-WP05-Tnn，可 `cargo xtask trace` 验证

## 非目标

- **C2PA 签发/嵌入**（Builder 写路径、动态断言）——按需另立（本 WP 只读校验+保留）
- **信任链验证**（TAU trust list 接入、Trusted 判定产品化）——verify_trust 显式关闭，
  后续作为配置项另立
- **远程 manifest fetch**（`fetch_remote_manifests`）——离线优先
- **PDF 容器**（c2pa `pdf` feature）——不开
- **dataset_export 含 c2pa 清单字段**——留 WP06/M5 评估
- **CAWG identity assertion 验证**（async identity 池）——后续

## 风险与开放问题

| 风险 | 处置 |
|---|---|
| c2pa 依赖树面积（coset/x509-parser/cbor 等 30+ crates） | cargo deny 实测；multiple-versions=warn 容忍；bans 无新 deny 冲突则零豁免进场 |
| 真实世界 manifest 兼容性（多 ingredient/大清单） | 自签样本覆盖结构路径；真实库冒烟登记开放项 |
| blob+列双写的存储成本 | manifest JSON 通常 KB 级，可接受；后续可裁 blob 通道 |
| Ed25519 生态清单（rust_native 已含 ed25519-dalek，无兼容问题） | 已核实源码，无行动项 |
