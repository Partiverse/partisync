# SPEC: M0-WP07 —— M0 达标验收（KPI 与关门材料）

版本: 1.0 · 状态: 批准 · 关联: 执行方案 §6.1-WP07、调研方案 §7 KPI 表 · 上游: M0 全部工作包
负责人: @lead · 批准日期: 2026-09-18

## 动机

M0 的出口条件（执行方案 §6.1 DoD）：**10⁶ 文件索引 <10 分钟**（Apple Silicon 笔记本口径）、
去重报告可见、find 毫秒级、属性测试/变异分数达标。本工作包执行实测并出关门材料。

## 验收标准（可执行）

- [ ] `gen-fixture --files 1000000` 生成的树上索引 <10 分钟（600s，`time` 实测，报告留档）；
- [ ] 去重报告（文件级 + 块级 saved_bytes）对百万库可见且数值合理（dup_rate 0.35 ⇒ 节省 ≈30%±10%）;
- [ ] `find`/`ls` 在百万库上交互可响应（<1s 量级，SQLite LIMIT 保障）;
- [ ] 常规门禁：fmt/clippy/test 全绿；core+cas 变异分数维持 ≥60%（例行复跑）；
- [ ] M0 里程碑报告终版（G3 材料）：全部 WP 汇总 + KPI 达标表 + 证据链接 + 签字区（人工待签）。

## 非目标

并行索引（单线程 walk 已达 KPI 则推迟）；覆盖率工具接线（CI 任务，随远端落地）；
10⁷ 压测（M1+）。

## 涉及文件清单

docs/reports/**、scripts/**（无产品代码变更——达标实测阶段）

## 风险与开放问题

- 1M 夹具生成本身耗时数分钟（I/O 为主）→ 后台执行，不计入索引 KPI；
- 索引器全局排序的内存峰值（1M PathBuf ≈100MB 量级）→ 实测记录；流式化归 WP07 后续/M1。
