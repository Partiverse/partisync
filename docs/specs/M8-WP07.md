## 1. 动机

一期把挂载面立成产品依赖图内的「诚实非 POSIX」只读面（P15 转正，
11 探针绿），但 CAS 资产对 POSIX 工具链仍是单向的：编辑器改不了已
存在文件，`rm`/`mv` 一律 EPERM。调研方案 §5.13 明确差异化定位：
**覆盖/改名/删除走本地写回日志 + overlay——这是 mountpoint-s3 明确
不做、而 PartiSync 有本地索引可以做的**。同时 `/by-hash/<blake3>`
内容寻址只读命名空间（M8-WP01 §4 非目标项）让脚本/流水线可以按
digest 稳定引用资产，不依赖路径。

不做则挂载面停在「可读不可改」：用户态写操作仍要退回 CLI/桌面壳，
FUSE 网关（ADR-0015）的最后一角缺写面，差异化叙事无法兑现。

## 2. 契约（草稿级，批准即冻结）

### 2.1 写回面（一期拒绝面的有条件开放）

| 操作 | 二期语义 |
|---|---|
| unlink / rmdir | 写回日志路径：日志项先落盘 → 应用到 backing → 索引接线（§2.3）；rmdir 仅空目录 |
| rename | 写回日志路径（同挂载点内；跨目录允许，目录拓扑仍由同步管线管理） |
| 写打开已存在文件 | 进入写回暂存：写入 overlay 暂存区，release/fclose 时按「整文件替换」原子应用（非随机写、非就地改） |
| truncate（setattr） | 作为整文件替换特例（截断到 0 = 清空写） |
| mkdir / mknod / symlink | **维持 EPERM**（目录拓扑由同步管线管理，一期语义不变） |
| 写回失败语义 | 日志项应用失败 → backing 保持原状（先日志后应用，拒绝先于破坏性效果不变量延续） |

### 2.2 CAS `/by-hash` 视图

- 挂载根下新增 `by-hash/blake3/<digest>` 只读命名空间：lookup/getattr/
  read 直连 CAS；任何写类操作 → `EROFS`；
- digest 不存在 → ENOENT；命名空间与目录视图并存于同一挂载；
- 读路径性能不劣于一期目录透传口径（§3 基准项）。

### 2.3 索引接线（本 WP 最大新面）

- 写回应用成功后**必须**产生 graph 事件并触发 Merkle 重算（复用
  M5-WP08 EventApplier/GraphApplier 闭环），保证「挂载面写 = CLI 写」
  的一致视图；接线面（sync/graph 侧入口）在实施任务卡定稿；
- 写回日志为 write-ahead：crash 后重放幂等（同一日志项重放一次生效，
  重放 N 次结果一致）；backing 不得出现半提交状态。

### 2.4 冻结不变量（沿一期）

- `DefaultPermissions` 关闭 + 宿主自管权限判定（ADR-0026 前置条件 1
  处置不变）；
- 拒绝先于破坏性效果（P15 延续）；SEMANTICS.md 随本 WP 修订走
  **ADR-0026 修订登记**（版本 bump，不新开 ADR）。

## 3. 验收标准（可执行）

- [ ] **写回探针扩展**：`probe_mount.rs` 增列——①unlink/rmdir/rename
      经日志路径生效且索引可见 ②已存在文件写打开 → release 后整文件
      替换 ③mkdir/mknod/symlink 仍 EPERM ④日志应用失败时 backing 原样；
- [ ] **crash 矩阵**：kill -9 于写回中途（日志已落盘/未落盘两相位）→
      重挂后 backing 无半提交状态、日志重放幂等（proptest，≥1000 例）；
- [ ] **索引接线 e2e**：挂载面写 → `partisync find` 命中新内容；
      Merkle 根与 CLI 直写路径一致；
- [ ] **`/by-hash` 探针**：digest 命中读、ENOENT、写类 EROFS、与目录
      视图同挂载并存；
- [ ] **基准**：整文件替换延迟（1 MiB/64 MiB）、`/by-hash` 读与一期
      目录读对照无回归（口径沿 M8-WP01-bench §1，drop-caches）；入
      `docs/reviews/M8-WP07-bench.md`；

- [ ] 三件套零新增豁免 + CI 全绿（探针环境门控 SKIP 路径沿一期）；

      ADR-0026 修订登记表 bump。

## 6. 风险与开放问题

| # | 风险 | 概率 | 影响 | 处置 |
|---|------|------|------|------|
| R1 | 挂载面写绕过索引/E2EE 管线 → 视图漂移（本 WP 最大风险） | 中 | 高 | §2.3 接线为验收硬项；e2e 探针「挂载写 = CLI 写」同根校验 |
