## 裁定总览

1. **基准位置**：`crates/partisync-index/benches/wp05.rs`（criterion 已是
   既有 dev-dep 口径，M3-WP01/02 benches 同款 harness = false）+ 集成测试
   `tests/m5_wp05.rs`（规模仿真正确性 + 可选 ignored 基准）。
2. **D5 口径（验收线）**：BM25 top-10 @10⁶ 文档 P99 < 100ms；usearch 向量
   top-10（768 维 Cosine）与 hybrid RRF top-10 @2×10⁴ P99 < 100ms / < 150ms。
   **修订记录（T02 执行期）**：向量语料从 10⁶ 缩至 2×10⁴——基准实测
   usearch `add` 在 release + 预 reserve 下仍 ~16ms/条（768d），10⁵ 构建
   ~27min、10⁶ ~4.4h，不可运营；同轮发现并修复 `upsert` 无条件
   `remove`/`contains` 超线性缺陷（fresh-key 快路径 `add_new` +
   `reserve` 预分配）。10⁵+ 向量口径补测归后续卡（查 usearch C 层
   编译/探测参数，疑 SIMD 未启用）。
3. **元数据仿真口径**：`graph::Store` 10⁶ entry upsert 吞吐 + path 查询
   P50/P99 + 进程 RSS 峰值（`/usr/bin/time -l` 外部采样，不入进程内）——
   对照 M3-WP01 10⁷（109k/s / LIST p99 36.1ms / 182.3B/条目）登记外推表。
4. **评测集沿用 M4-WP06**：`eval::runner` 三档模式不动；本 WP 只补吞吐
   基准，IR 质量指标（Recall/MRR/nDCG）以 M4-WP06 既有 synthetic 语料
   结果引用，不重跑（D7 才换真语料）。
5. **D6/D7 处置**：报告显式标注 `gated: 外网 HF 可达` / `gated: 真实
   数据面接入`；M4-report §5 D5 行更新为「已清偿（M5-WP05）」，
   D6/D7 维持 M5+ 状态不虚报。
6. **零新增依赖**：criterion/tantivy/usearch/serde_json 全既有；
   RSS 采样用 shell 外部命令，进程内不引 libc。

## 风险与开放问题

- **10⁶ 语料构建耗时**：确定性合成（LCG 词选择）+ 批量 upsert；构建
  一次性落盘复用（bench target 目录），目标 < 5min。
- **usearch 内存**：10⁶ × 768 × 4B ≈ 3GB 向量驻留——CI runner 内存上限
  风险；基准登记 `--ignored`（本地显式跑），CI 只跑正确性小规模冒烟
  （10⁴ 文档口径）。
- **RSS 采样跨平台**：`/usr/bin/time -l` macOS 口径；Linux 用
  `/usr/bin/time -v`——报告注明环境，不抽象工具。
