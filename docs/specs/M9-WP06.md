## 1. 动机

v0.1.0-alpha（2026-10-01 publish）之后产品累积了两个里程碑的增量面——
M8 WP05–WP07（桌面五 tab 功能面 / epoch-fuel 终止 / FUSE 写回二期 +
`/by-hash`）与 M9 WP01–WP05（写路径闭环装配层 / 可验证记忆层 / 桌面

## 2. 契约

### 2.1 beta 口径（推荐落锤；**待用户确认后执行发布**，M9-WP00 §2 拍板项④）

| 轴 | 推荐 | 理由 / 依据 |
|---|---|---|
| 版本号 | tag `v0.1.0-beta`；Cargo workspace / tauri version 维持 `0.1.0`；产物文件名由 release.yml 打包步显式加 `-beta` 后缀（如 `partisync-cli-0.1.0-beta-linux-x86_64.tar.gz`、`PartiSync.Desktop_0.1.0-beta_aarch64.dmg`） | Cargo pre-release 版本（`0.1.0-beta.0`）不满足 path-dep `version = "0.1.0"` 约束（hub Cargo.toml:11-14 判例），全图改版本约束改动面与收益不成比；alpha 同构（tag 携 pre-release、Cargo 0.1.0）；产物名加后缀避免与 alpha 同名混淆（alpha 判例名 `PartiSync.Desktop_0.1.0_aarch64.dmg`，release-report §1） |
| 产物面 | 三产物框架维持：CLI（linux x86_64 + macOS aarch64 tar.gz）、desktop dmg（macOS aarch64）、hub 侧随 linux 包；tar 包内扩二进制：`partisync-cli` + `partisync-mcp`（MCP stdio server，记忆三工具）+ `partisync-fuse`（挂载入口含 `--graph` 装配层）；linux 包 hub 产物仍 = `hub-demo-web` | beta 叙事 = 写回 + 记忆，两面的实际入口分别是 `partisync-fuse` 与 `partisync-mcp`（gateway src/bin 判例），不进产物面则叙事无载体；hub 正式服务 bin 至今未立——release-report §4-4 债延续，如实标注 demo 面，不冒充生产 |
| 是否含 FUSE 写回 | **含**（写回 + `/by-hash` + `--graph` 装配层） | M8-report §8-4 原文定位；风险面已有 P16 重放幂等 1024 例 ×4 场景 + crash 矩阵 + 容器真挂载 e2e（M9-WP01-T03 PASS 0.20s）覆盖；SEMANTICS 登记边界（tick 轮询非实时 / 单挂载点 / max-delete 阈值）作为已知限制写入 release notes，不假绿 |

三轴均为推荐案：用户确认（或修订）后由 T03 执行发布；确认前不 tag、
不建 Release、不 publish。若用户修订口径，本 SPEC 修订版本号登记。

## 6. 风险与开放问题

- **R1 口径未确认即推进 T02**：产物面/后缀改动是 release.yml 实改，
  若用户修订口径需返工——T02 开工前置 = 用户对 §2.1 三轴至少不反对
  （默认推荐案静默确认沿用户极简指令协作模式，与「执行发布需显式
  确认」相区分）。
- **R2 reproducibility 对照可能暴露 Linux 产物不可复现**（构建路径
  /时间戳嵌入）：如实登记偏差清单（M8-WP02 R1 判例），不放宽门禁、
  不假绿；不可复现根因项挂修订。
- **R3 drop-caches 复测环境不可得**（无 Linux 容器/FUSE device 窗口）：
  债不顺延第三次——报告以「环境不可得 + 手动档命令链交付」形式落盘，
  复测保持窗口开放，如实标注未执行。
- **R4 产物面扩 bin 的体积/安全面**：partisync-fuse/partisync-mcp 入
  包扩大二进制分发面（fuser/wasmtime 传递面）——auditable + deny 门禁
  不变；体积如实记录于发布报告，不做裁剪承诺。
- **R5 changelog 草稿与最终 Release notes 漂移**：T03 publish 前以
  本仓 CHANGELOG.md 为正文源（T02 关闭 generate_release_notes 或
  保留为附录，实施时二选一登记）。
