## 动机与范围

M5-WP04 v0.1 的 `apply_one` 为 stub（事件不落图谱）。本卡闭环：
`EventApplier` trait + `GraphApplier`（graph::Store 后端）。零新依赖。

## 裁定

1. **applier 挂 `EventOpts.applier: Option<Arc<dyn EventApplier>>`**——
   不改 `apply_batch` 签名（既有测试零改动）；None = stub 行为原样。
2. **GraphApplier 语义**：Created/Modified → `add_entry`（幂等 upsert；
   size/mtime 自 payload `.size`/`.mtime_ns`，缺省 0）；**父目录链自动
   建**（逐级 ensure Dir 幂等——云对象 key 是 flat path，图谱需树一致）；
   Removed → `remove_entry`（幂等，删 0 行不报错）。name = path 尾段。
3. **与 journal 通路关系**：`journal::apply_pending` 面向本地 fs 事件
   （fs metadata 校验）；云事件直写 graph（无本地 fs 可查）——两通路
   并存，口径已在代码注释说明。
4. **验收**：created→entry 存在且 size 对；modified→刷新；removed→
   消失（幂等重放不报错）；父目录链自动建（a/b/c.txt 三级）。
