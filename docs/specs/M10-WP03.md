## 1. 动机

M9-WP03（桌面深耕一期）实施面 2026-10-04 收官（PR #135–#140），但
SPEC §3 打勾表唯一未勾行就是 **T04 GUI 人工验收**：记忆 tab 三态截图
归档 + 全 tab 巡检 + 篡改红徽章演示（`M9-WP03.md:131-134`，登记
「待人工 GUI」）。M10-WP00 §2 拍板项 #5 已裁定「T04 GUI 随 WP03」
承接（不占新编号）。这笔尾款不清，M9-WP03 不能真关账——记忆面板
（α 主线核心资产的用户面）从未被 GUI 实操验证过承诺验证徽章的
失败态，AGENTS.md 桌面端硬性规则的证据链缺一环。

同时，浏览/详情是七大 tab 中最早交付的功能面（M8-WP05-T02），却停
留在最小可用：**详情面板没有关闭能力**——`showDetail`
（`app-core-v3.js:129-157`）面板一旦打开无法关闭（模板无 × 按钮、
无 Esc 接线），aside 常驻挤压表格区，只能换内容不能收起；**完整
content_id 与副本路径不可复制**（面板只显 16 字符切片 + `…`，MCP/
CLI 联调要开 DevTools 抄）；**修改时间不在详情面板**（载荷
`AssetDetail.copies: Vec<EntryRow>` 已含 `mtime_ns`，
`ipc.rs:223-227`，纯前端没渲染）；**浏览表头是死的**（
`index.html:44` 四列静态 th，名称/大小/修改时间不可排序）；**mtime
列只有绝对本地时间**（`timeFmt`，`app-core-v3.js:43-48`，与 M10-WP02
指认的记忆面板时间问题同型）。不做本 WP：M9 尾款持续悬挂、浏览/
详情作为日常主入口的体验与 M10-WP01（检索）/M10-WP02（记忆）深化
后的 tab 拉开落差，直接抵消 M10「GUI 功能加速」主线。

### 2.1 T01：M9-WP03-T04 GUI 三态验收承接 + 全 tab 巡检（人工件窗口，kind=gui）

- **三态截图（M9-WP03 §2.4 原样清偿）**：记忆 tab
  1. 全空态（空库初始）；
  2. 有数据态（经 GUI `memory_write` 写入 ≥2 条含 tags 记忆后：
     列表 + 验证徽章绿 + root hex 在镜）；
  3. 验证失败态（篡改演示：见下）。
- **篡改红徽章演示（安全流，硬约束）**：memory 库是生产库
  `~/.partisync/graph.db`（gateway 侧默认，`mcp.rs:313-317`）——只
  允许动本演示自写的行：GUI 写入演示行 → 退出桌面 app（sidecar
  释放 DB）→ `cp graph.db /tmp/…bak` 备份 → `sqlite3` UPDATE 该演示
  行 content → 重启 app → 面板对 root 徽章红 + 行级验证红截图 →
  删除演示行收尾。**严禁改演示行以外的任何行；演示后演示行不留库**。
- **全 tab 巡检**：7 tab（浏览/检索/记忆/同步/重复内容/作业/扩展）
  逐一过 + 每 tab ≥1 帧截图；检索 tab 帧须含 M10-WP01 已交付件在镜
  （filename 命中卡 / 扩展名 chips / 索引规模徽标，任一即可——该
  SPEC §2.1「随巡检窗口」遗留的对账注记）。
- **GUI 工具链判例（M8-WP05-ui-report §6，硬性）**：WKWebView 对
  cliclick 合成点击在部分静态按钮上不派发 onclick——走 macOS
  Accessibility **AXPress**；输入 setValue 遭智能引号替换——空参调用
  或含数字值 JSON 绕行；截图归档是验收硬性条件，环境不可得时 PR
  保持 OPEN 打 label「待 GUI 验证」，不得合入。
- **回填（清账动作）**：`docs/specs/M9-WP03.md` §3 T04 行勾选 +
  `docs/specs/M9-WP00.md` §1-WP03 行更新（T04 已清）；截图归档
  `docs/screenshots/M10-WP03-T01-*.png`。
- **不顺手修**：巡检若发现新缺陷 → 登记本 SPEC 修订或另立任务
  （铁律 9），不在 T01 内改代码。

### 2.2 T02：详情面板 UX（关闭 + 信息补全 + 复制）

- **关闭能力**：面板头部 × 按钮 + Esc 键两通道关闭；关闭 =
  `display:none` + 面板内容清空；**硬约束：关闭不得清空/重载浏览
  列表，不得重发任何 IPC**（沿 M10-WP01 §2.3「不清空结果」判例）；
  再点行可重开。Esc 仅在面板可见时生效，不抢输入框焦点语义。
- **信息补全（零 IPC 变更）**：面板增「修改时间」行 = 首副本
  `copies[0].mtime_ns`（与 `size` 取 `rows.first()` 同口径，
  `ipc.rs:238`）；副本列表 ≥2 时标注「N 处副本」既有语义不变。副本
  行 mtime_ns 缺失/0 → 「—」回落。
- **复制**：完整 content_id（64 hex 全量，替代「抄 DevTools」）+
  每条副本路径「复制」按钮 → `navigator.clipboard.writeText`；成功
  反馈 = 按钮文案瞬时「已复制」→ 1.5s 回落（沿 M10-WP02 §2.2
  契约）；API 不可用回落方案实现期定（§7-R2）。
- **转义不变量**：新增模板动态段（mtime/复制按钮 aria-label 等）
  esc() 全覆盖，不得出现未转义插值（沿 M9-WP03 §2.1 esc 契约）。

### 2.3 T03：浏览列表 UX（表头客户端排序 + mtime 相对时间）

- **表头排序（客户端）**：名称 / 大小 / 修改时间三列可排（内容身份
  列除外）；点击按当前渲染行集排序，再点反序，第三点回服务端序
  （`list` → `children()` 返回序，`ipc.rs:90-96`）；表头箭头指示
  当前排序键与方向；**换目录（面包屑/目录行导航）后排序态重置为
  默认**（沿 M10-WP02 T01「新检索重置」判例）。排序键相同时目录行
  （kind=1）恒排在文件行前（次级键 kind 降序，文件管理器惯例）。
  诚实边界：`children()` 无分页、全量返回该目录条目——排序作用于
  全集，无「窗口序」误读面。
- **mtime 相对时间**：mtime 列改相对显示（复用既有 `relTime`，
  `app-core-v3.js:473-481`），**>30 天回落绝对日期**（relTime 现无
  回落档——本卡自含实现，不依赖 M10-WP02-T03 落地顺序；若其先合入
  则直接复用其扩展）；title 悬浮 = `timeFmt` 完整本地时间（不回退）；
  mtime_ns 缺失/0 → 既有「—」回落。
- **空态不回退**：browse 空态文案（D6 动作邀请修复，
  `app-core-v3.js:118`）维持原文不动。
